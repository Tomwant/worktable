来源怎么标：绿标「官方一手」= 直接来自厂商博客、changelog、System Cards 或 API 公告，链接点开就是官网原文；灰标「媒体报道」= 官方没给可引用的独立页面，取自可靠媒体或第三方版本总表，同样附原始链接。
日期口径：同一版本在不同媒体上可能差 1 天（时区或分批推送），统一按「官方首发日」记；官方只到月份的，用第三方版本总表补齐并标灰。
关于本页：这是原型稿，数据为 2026-10-26 抓取并逐条核过的真实快照（近一年 59 条 + 一年前 4 条），其中 33 条能追到厂商官网原文。正式实装后由每日任务自动补新，抓不到一手来源的条目标灰并标注「未核实」。
