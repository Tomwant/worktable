一、故事引入：阿明的"神秘奶茶"盲测

阿明研发了一款新品奶茶，纠结到底用配方甲还是配方乙。市场真实更受欢迎的是其中某一个，但他并不知道。于是他请来 10 位好友，依次盲尝、并当众宣布自己选甲还是选乙（一旦喊出口不能改）。

规则很关键：

  • 每个人先私下抽一张"口味卡"——红卡偏向甲、蓝卡偏向乙，卡片指对真实赢家的概率是 q = 2/3（比瞎猜准一点，但不是绝对）。
  • 每个人听得到前面所有人宣布的结果，但看不到别人的卡片，也听不到别人的理由。

阿强第一个抽到红卡 → 喊"甲"。

阿珍第二个抽到红卡 → 喊"甲"。

现在轮到阿明（第三个）。他私下抽到的是一张蓝卡（指向乙）！可他看到前两个人都喊了甲。他心里一算：前面两人异口同声选甲，这本身已经传递了大量信息——"两个独立信号都指向甲"。于是阿明也跟着喊甲，把自己的蓝卡扔到一边。

这就是信息级联的起点：从第三个人起，只要前面同声，后面所有人都会照搬前面的公开选择，哪怕自己的私有信号完全相反。故事里哪怕后面 100 个人都抽到蓝卡，只要最开始那两位同色，全队都会喊甲。

想一想：阿明明明抽到了"相反"的卡片，为什么理性上却该跟甲？他丢掉的那张蓝卡，到底还有没有价值？

二、概念讲解

1. 什么是信息级联

信息级联（informational cascade）：当后面的人观察到前面人的公开行动后，发现自己的私有信息已经改变不了最优决策，于是放弃私有信号、完全照搬前面行动的现象。群体表现出"羊群"，但每个人都是理性地在做贝叶斯更新——这叫理性从众。

注意区分两种"跟风"：

  • 信息级联（理性）：你真以为"前面的人更懂"，因为他们公开的行为暴露了一部分信息。
  • 声誉从众（非信息）：你其实知道别人可能也瞎跟，但怕显得无知或异类而附和（阿施线段实验、会议里没人敢反对）。

本期只讲第一种——它最反直觉：明明人人理性，群体却可能集体翻车。

2. 贝叶斯机理：公开行动是私有信号的"有损聚合"

设先验 P(甲对)=P(乙对)=1/2，卡片准确率 q=2/3。

前两个人都喊甲传递了什么？用贝叶斯算 P(甲对 | 前两人选甲)：

  • 若甲真对，两人都抽到红（喊甲）的概率 = q²；
  • 若乙真对，两人都抽到红（喊错）的概率 = (1−q)²。
P(甲对 | 前两人选甲) = q² / [ q² + (1−q)² ]
= (4/9) / (4/9 + 1/9) = 4/5 = 0.8

也就是说，光看前两个人的公开选择，甲的后验已经从 0.5 升到了 0.8。第三个人即使自己抽到蓝卡（指向乙），把这张私人证据再乘进去，甲的后验仍高于 0.5（具体算法见第四节题 1），于是理性地选甲。

核心洞察：公开行动 = 私有信号的"压缩包"，它丢掉了"为什么"，只留下"选了啥"，但承载的信息量仍可能大于你手里的单张卡片。级联的根因正是——信号私有、只见行动。

3. 级联的"脆弱"与"顽固"

  • 顽固：一旦级联启动，会一直持续，因为后面每个人算出来都该跟。哪怕连续 100 个蓝卡，只要开局两位同色，全跟甲，没人纠错。
  • 脆弱（可被打破）：只要有人公开自己的私有信号（不只喊结果），或信号精度突变、出现权威新信息、允许改口重估，级联立刻瓦解。
  • 错误代价：级联一旦朝错误方向启动，群体最终选错的概率高得惊人（经典结论见题 2）。

4. 闭环前面几期

  • 接第 2 期贝叶斯定理：级联本质就是"把别人的公开行动当新证据做后验更新"。
  • 接第 12 期马尔可夫链：级联可看作进入了一个"吸收态"——一旦跟从，再也出不去。
  • 对照第 8 期蒙特霍尔：主持人"故意不开车"也是一种信息注入；级联是"别人无意间泄露的信息"。
  • 对照第 20 期最优停止：前面讲"何时该自己停手判断"，本期讲"何时该放弃自己的判断去跟"——一对反向张力。

三、代表性题目（你来总结，写完后看第四节对照）

题 1（级联起点）：把卡片准确率降到 q = 0.6（只比瞎猜准一点）。前两人都喊甲，第三个人抽到的却是指向乙的信号。他是该跟甲，还是该信自己的卡片？请写出后验概率。
题 2（级联的错误率）：在 BHW 经典模型（先验 1/2、q = 2/3）下，信息级联一旦启动，群体最终选择方向错误的概率大约是多少？为什么理性个体也会把大家带沟里？
题 3（破级联）：如果规则改成——每个人不仅当众喊"甲/乙"，还要亮出自己的卡片颜色（红/蓝），级联还会发生吗？为什么？
题 4（现实映射）：下面哪些更接近"信息级联"（理性从众），哪些更接近"声誉从众"？各举一个你身边的例子：① 早起跟风买某只基金，因为"前面的人都赚了"；② 会上明知方案有漏洞却无人反对；③ 看论文引用量判断该读哪篇；④ 直播间抢购。

四、完整解题思路（含答案）

题 1 解答
先算"前两人都选甲"给甲的后验：
P(甲 | 前两人甲) = q² / [q² + (1−q)²]
= 0.36 / (0.36 + 0.16) = 0.36 / 0.52 ≈ 0.6923。
第三个人自己抽到蓝卡（指向乙）。把这条私人证据乘进去：
- 若甲真对，他抽到蓝（错卡）的概率 = 1−q = 0.4；
- 若乙真对，他抽到蓝（对卡）的概率 = q = 0.6。
复合后验：
P(甲 | 前两人甲，且自己蓝)
= [0.6923 × 0.4] / [0.6923 × 0.4 + (1−0.6923) × 0.6]
= 0.2769 / (0.2769 + 0.1846)
= 0.2769 / 0.4615 ≈ 0.60。
结论：即便自己的证据相反、信号精度也只有 0.6，聚合的前两人信息仍占上风（0.60 > 0.5），理性选择是跟甲。这正是级联的起点——公开行动承载的信息量 > 单张私有卡。
题 2 解答
BHW（Bikhchandani–Hirshleifer–Welch, 1992） landmark 结论：当 q = 2/3、先验 1/2 时，信息级联几乎必然会发生（n 足够大），而级联一旦启动，群体最终选择方向错误的概率约为 1/3（正确方向约 2/3）。
直觉拆分：级联始于"前两个同色信号"。同色既可能来自真信号同向（概率 q² = 4/9），也可能来自假信号同向（概率 (1−q)² = 1/9）。在"启动即同色"的条件下，方向错的概率 = (1/9) / (5/9) = 1/5；但更长的链里级联可能在更晚才启动，综合下来经典结果为错误级联 ≈ 1/3。
为什么理性个体带沟里：每个人都在正确做贝叶斯，但信息通过"公开行动"有损传递，早期一两个同色信号就把后验推过 0.5，之后所有人被锁死，私有反例信号再也无法改变公开结论。个体理性 → 集体非理性。
题 3 解答
级联不会发生。原因：一旦每个人亮出卡片颜色，所有人的决策就基于全部私有信号 + 自己的信号的完整证据，相当于"少数服从多数 / 贝叶斯聚合全体信息"，不再依赖"只看别人选了啥"。
关键区别：公开行动是信息的"有损压缩"（只显结果不显理由），级联的根因正是信号私有 + 只见行动。信息充分披露后，每个人判断依据完整，级联失去土壤。
现实启示：匿名可复核投票、公开原始数据、可审计方法、要求"说出你的依据"——都能打破信息级联。
题 4 解答（参考框架）
- 信息级联（理性，基于他人行动推断信息）：① 跟风买基金（"前面都赚了"= 用他人行为推断标的优劣）；③ 看引用量选论文（用引用量推断质量）。
- 声誉从众（怕显得异类/无知）：② 会上无人反对（明知有漏洞也附和，阿施实验原型）。
- 两者叠加：④ 直播间抢购——既"看别人抢以为好"（信息），又"怕错过/怕显得不懂"（声誉）。
区分口诀：信息级联里你真以为别人更懂；声誉从众里你知道别人可能也瞎跟，但不敢出头。
