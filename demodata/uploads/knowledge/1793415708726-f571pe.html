第 7 期 · 隐马尔可夫模型（HMM）：看不见的状态，藏得住的真相

今日一句话：有些东西你永远无法直接看到——大刘此刻是开心还是烦躁，你只能看到他发的表情包。HMM 就是用来"隔着观测猜隐藏状态"的数学机器。

一、故事：阿明读不懂大刘的表情

阿明和大刘是同事。大刘最近情绪忽明忽暗，但从不直说自己心情好坏，只会在群里发表情包：要么是 😊 微笑，要么是 😠 皱眉。

阿明发现一个规律：

  • 大刘今天开心，明天多半还开心；今天烦躁，明天多半还烦躁（心情有惯性）。
  • 但心情和表情不是一一对应的：他开心时大多发 😊，偶尔也发 😠（比如手滑）；他烦躁时大多发 😠，偶尔也发 😊。

于是阿明手里只有一串看得见的表情序列，却想反推出大刘看不见的心情序列。

问题来了：

  • 给你一段表情（微笑、皱眉、微笑…），大刘最可能经历了一段怎样的心情起伏？
  • 这段表情序列，在"大刘的脾气模型"下，出现的可能性有多大？
  • 如果连"脾气模型"的参数都不知道，能不能从一大堆表情记录里自己学出来？

这三个问题，正好是 HMM 的全部核心。HMM = 带观测的马尔可夫链（闭环第 12 期：马尔可夫链只管状态，HMM 再叠一层"状态生成观测"）。

二、概念讲解

1. HMM 的五个零件（五元组 λ = (S, O, A, B, π)）

  • S（隐藏状态集）：你看不到的真相。例：{开心 H, 烦躁 G}。
  • O（观测集）：你能看到的信号。例：{微笑, 皱眉}。
  • A（转移矩阵）：状态之间的转移概率 Aᵢⱼ = P(q₍t+1₎=j | qₜ=i)。这就是第 12 期的马尔可夫链（每行和为 1）。
  • B（发射矩阵 / 观测概率）：在某一状态下"发出某个观测"的概率 Bᵢ(k) = P(oₜ=k | qₜ=i)。
  • π（初始分布）：第 1 步各隐藏状态的先验概率 πᵢ = P(q₁=i)。

两条基本假设（HMM 的命脉）：

  1. 马尔可夫性（接第 12 期）：P(qₜ | qₜ₋₁, …, q₁) = P(qₜ | qₜ₋₁)，未来只取决于"现在"。
  2. 观测独立性：P(oₜ | qₜ, qₜ₋₁, …, oₜ₋₁) = P(oₜ | qₜ)——给定当前状态，观测与历史无关。
直觉：HMM 像一条"内部心情链"在暗中走，每走一步就吐出一个表情给你看。你看到的是表情，猜的是心情。

2. HMM 的三大经典问题

| 问题 | 名字 | 你要算什么 | 算法 |

|---|---|---|---|

| 评估 | 前向概率 | 给定模型 λ，某段观测 O 出现的概率 P(O|λ) | 前向算法 / 后向算法 |

| 解码 | 最可能状态序列 | 给定 O 与 λ，找最可能的隐藏路径 | Viterbi（动态规划） |

| 学习 | 参数估计 | 只给一大堆 O，反推 A、B、π | Baum-Welch（EM 的 HMM 版，闭环第 26 期变分推断/EM） |

3. 前向算法：为什么不用暴力？

暴力做法：枚举全部 Nᵀ 条隐藏路径，逐条算概率再求和。当 N=2, T=100 时，路径数 2¹⁰⁰ ≈ 10³⁰——宇宙原子数都不够用。

前向算法用递推把复杂度砍到 O(T·N²)：

定义 αₜ(i) = P(o₁, o₂, …, oₜ, qₜ=i | λ)，即"前 t 步观测都对、且第 t 步藏在状态 i"的联合概率。

  • 初始化：α₁(i) = πᵢ · Bᵢ(o₁)
  • 递推：αₜ₊₁(j) = [ Σᵢ αₜ(i)·Aᵢⱼ ] · Bⱼ(oₜ₊₁)
  • 终点：P(O|λ) = Σᵢ αₜ(i)

每一步把"之前所有路径"压缩成一个数字，绝不重复枚举。

4. Viterbi：解码用动态规划

前向算法求的是"概率之和"，Viterbi 求的是"概率最大的一条路径"。

定义 δₜ(i)（走到第 t 步停在状态 i 的最大路径概率），再配一个指针 ψₜ(i) 记下"上一步从哪个状态来"。

  • 初始化：δ₁(i) = πᵢ·Bᵢ(o₁)，ψ₁(i)=0
  • 递推：δₜ₊₁(j) = maxᵢ [ δₜ(i)·Aᵢⱼ ] · Bⱼ(oₜ₊₁)，ψₜ₊₁(j)=argmaxᵢ(…)
  • 回溯：从 argmaxᵢ δ_T(i) 沿 ψ 倒着走回起点。

5. 应用版图（你会发现处处是 HMM）

  • 语音识别：声学特征=观测，音素/口型=隐藏状态。
  • 词性标注：词的词性=隐藏状态，看到的词=观测（见题 3）。
  • 生物信息：基因序列里"编码区/非编码区"=隐藏状态，碱基=观测。
  • 故障诊断：机器"正常/故障"=隐藏状态，传感器报警=观测。
  • 量化金融：市场"牛/熊/震荡"=隐藏状态，收益率=观测。
  • 闭环：第 12 期马尔可夫链（HMM 的骨架）、第 2/8 期贝叶斯（后验即解码）、第 15 期蒙特卡洛（粒子滤波用采样做 HMM 推断）、第 26 期变分推断与 EM（Baum-Welch 即 EM）。

- 发射矩阵：H 时 微笑=0.8/皱眉=0.2；G 时 微笑=0.3/皱眉=0.7
- 观测序列 O = (微笑, 皱眉)
（a）用前向算法求 P(O)；
（b）用 Viterbi 求最可能的隐藏状态路径。

四、完整解题思路与答案

题 1 解答

模型复述（方便对照）：

π = (0.6, 0.4)；A：H→H 0.7 / H→G 0.3 / G→H 0.4 / G→G 0.6；

B：H→微笑 0.8 / H→皱眉 0.2；G→微笑 0.3 / G→皱眉 0.7。

O = (微笑, 皱眉)。

（a）前向算法

  • t=1（观测=微笑）：
  • α₁(H) = π_H · B_H(微笑) = 0.6 × 0.8 = 0.48
  • α₁(G) = π_G · B_G(微笑) = 0.4 × 0.3 = 0.12
  • t=2（观测=皱眉）：
  • α₂(H) = [α₁(H)·A_HH + α₁(G)·A_GH] · B_H(皱眉)

= [0.48×0.7 + 0.12×0.4] × 0.2 = [0.336 + 0.048] × 0.2 = 0.384 × 0.2 = 0.0768

  • α₂(G) = [α₁(H)·A_HG + α₁(G)·A_GG] · B_G(皱眉)

= [0.48×0.3 + 0.12×0.6] × 0.7 = [0.144 + 0.072] × 0.7 = 0.216 × 0.7 = 0.1512

  • 终点：P(O) = α₂(H) + α₂(G) = 0.0768 + 0.1512 = 0.228
答案：P(O) = 0.228。这一步把"HH、HG、GH、GG"四条两状态路径一次性压缩进两个 α，没有真的枚举。

（b）Viterbi 解码

  • t=1：δ₁(H) = 0.48（ψ=0），δ₁(G) = 0.12（ψ=0）
  • t=2（观测=皱眉）：
  • δ₂(H) = max(δ₁(H)·A_HH, δ₁(G)·A_GH) · B_H(皱眉)

= max(0.48×0.7=0.336, 0.12×0.4=0.048) × 0.2 = 0.336 × 0.2 = 0.0672，ψ₂(H)=H

  • δ₂(G) = max(δ₁(H)·A_HG, δ₁(G)·A_GG) · B_G(皱眉)

= max(0.48×0.3=0.144, 0.12×0.6=0.072) × 0.7 = 0.144 × 0.7 = 0.1008，ψ₂(G)=H

  • 回溯：终步 max(δ₂(H)=0.0672, δ₂(G)=0.1008) = 0.1008 → 选 G；

由 ψ₂(G)=H 回到 t=1 → 选 H。

答案：最可能的隐藏路径 = H → G（开心 → 烦躁），路径概率 0.1008。
关键洞察：前向算的是"所有路径概率之和 = 0.228"，Viterbi 找的是"概率最大的那一条 = 0.1008"。两者回答不同问题——这正是评估与解码的区别。

题 2 解答

（a）区别：纯马尔可夫链（第 12 期）的"状态本身就是你能看到/关心的量"，只研究状态之间的转移与平稳分布；HMM 的状态是隐藏的，你只能看到由状态"发射"出来的观测，多了一层 B（发射矩阵）。可记：HMM = 马尔可夫链 + 一层观测噪声。
（b）正确。这就是"观测独立性"假设：给定当前隐藏状态 qₜ，观测 oₜ 与更早的状态、更早的观测都独立，即 P(oₜ | qₜ, qₜ₋₁, …, oₜ₋₁) = P(oₜ | qₜ)。但注意——不给定状态时，观测之间一般不独立（它们靠隐藏状态"藕断丝连"，比如大刘连发两个 😊 暗示他连着开心）。
（c）前向算法省掉的是指数级的路径枚举。暴力法要列出全部 Nᵀ 条隐藏路径分别求和；前向递推在每一步把"到状态 i 的所有历史路径"合并成一个 αₜ(i)，复杂度降到 O(T·N²)，从"指数爆炸"变"线性×平方"，100 步也能瞬间算完。

题 3 解答（词性标注）

O = (苹果, 吃)。

  • t=1（观测=苹果）：
  • δ₁(N) = π_N · B_N(苹果) = 0.7 × 0.6 = 0.42
  • δ₁(V) = π_V · B_V(苹果) = 0.3 × 0.0 = 0.0
  • t=2（观测=吃）：
  • δ₂(N) = max(δ₁(N)·A_NN, δ₁(V)·A_VN) · B_N(吃)

= max(0.42×0.4=0.168, 0.0×0.6=0) × 0.1 = 0.168 × 0.1 = 0.0168，ψ₂(N)=N

  • δ₂(V) = max(δ₁(N)·A_NV, δ₁(V)·A_VV) · B_V(吃)

= max(0.42×0.6=0.252, 0.0×0.4=0) × 0.8 = 0.252 × 0.8 = 0.2016，ψ₂(V)=N

  • 回溯：终步 max(0.0168, 0.2016)=0.2016 → 选 V；ψ₂(V)=N → t=1 选 N。
答案：词性序列 = N → V（名词 → 动词），即"苹果(名词) 吃(动词)"，命中人类直觉。这就是统计词性标注的核心：模型从（词, 词性）语料里学会 A、B，再用 Viterbi 给新句子标词性。

题 4 解答

（a）三步 Viterbi（O = 微笑, 皱眉, 微笑）

沿用题 1 的 δ₁、δ₂：δ₁(H)=0.48, δ₁(G)=0.12；δ₂(H)=0.0672(ψ=H), δ₂(G)=0.1008(ψ=H)。

  • t=3（观测=微笑；B_H(微笑)=0.8，B_G(微笑)=0.3）：
  • δ₃(H) = max(δ₂(H)·A_HH, δ₂(G)·A_GH) · B_H(微笑)

= max(0.0672×0.7=0.04704, 0.1008×0.4=0.04032) × 0.8 = 0.04704 × 0.8 = 0.037632，ψ₃(H)=H

  • δ₃(G) = max(δ₂(H)·A_HG, δ₂(G)·A_GG) · B_G(微笑)

= max(0.0672×0.3=0.02016, 0.1008×0.6=0.06048) × 0.3 = 0.06048 × 0.3 = 0.018144，ψ₃(G)=G

  • 回溯：终步 max(δ₃(H)=0.037632, δ₃(G)=0.018144) = 0.037632 → 选 H；ψ₃(H)=H → t=2 选 H；ψ₂(H)=H → t=1 选 H。
答案：最可能的三步心情路径 = H → H → H（开心 → 开心 → 开心），路径概率 0.037632。
对照题 1：前两步在 "H→G" 与 "H→H" 间，加入第三个 😊 后，整体最稳的解释变成"其实他一直挺开心"，因为开心发 😊 的概率最高。可见 Viterbi 是全局最优路径，会"反悔"局部看似合理的选择。

（b）Baum-Welch（学习）思想

只有一大堆观测 O⁽¹⁾, O⁽²⁾, …，参数 A、B、π 未知。思路是 EM 算法（闭环第 26 期）：

  • E 步（期望）：用当前参数跑前向-后向，算出"在每条观测下，第 t 步处于状态 i、以及第 t 步在 i 且 t+1 步在 j"的期望次数（γₜ(i) 与 ξₜ(i,j)）。
  • M 步（最大化）：拿这些期望计数去重新估计参数——新的 Aᵢⱼ = Σₜ ξₜ(i,j) / Σₜ γₜ(i)，新的 Bᵢ(k) = Σₜ γₜ(i)·[oₜ=k] / Σₜ γₜ(i)，π 用第一步的 γ₁(i)。
  • 反复迭代，似然单调上升，直到收敛。
关系：Baum-Welch 就是 EM 在 HMM 上的具体化身；第 26 期的变分推断则是当精确 E 步算不动时，用"下界 + 优化"去近似它——二者同源，一个求精确，一个求可解。

（c）思考题答案（先想再看）

会不等于。 "每一步最可能的状态"（滤波/边际最优 argmaxᵢ γₜ(i)）和"最可能的整条路径"（Viterbi 的 argmax 路径）是两件事：前者是逐时刻边际最大化，后者是整条联合路径最大化。逐点最优拼起来，未必是联合概率最大的那一条（类似"局部贪心 ≠ 全局最优"）。这正是 Viterbi 存在的意义——它保的是全局最优路径，而不是每一步单独看起来最舒服的状态。

五、今日小结

  • HMM 是什么：一条你看不到的马尔可夫链（第 12 期），每步吐一个观测给你。
  • 五元组：S、O、A、B、π；两条命根子假设 = 马尔可夫性 + 观测独立性。
  • 三大问题：评估（前向，求 P(O)）、解码（Viterbi，求最优路径）、学习（Baum-Welch / EM）。
  • 为什么强：前向/后向把 Nᵀ 爆炸砍成 O(T·N²)；Viterbi 用动态规划拿全局最优路径。
  • 闭环复习：第 12 期（骨架）、第 2/8 期（贝叶斯后验）、第 15 期（粒子滤波=蒙特卡洛版 HMM 推断）、第 26 期（变分推断与 EM）。
