每日概率学 · 第 9 期

  • 日期：2026-10-05（周一）
  • 今日概念：随机变量与常见分布（Random Variables & Common Distributions）——把"随机的结果"翻译成"数字"的语言。一枚硬币落地是"正面/反面"，但只要你规定"正面 = 1、反面 = 0"，运气就成了一条可以被计算、被加总、被画成曲线的随机变量 X。不同的"世界生成机制"对应不同的分布：抛一次的 0/1（伯努利）、抛 n 次数正面（二项）、骰子 1–6 等可能（均匀）、单位时间里的稀有事件计数（泊松）、以及由无数微小扰动叠出来的钟形曲线（正态）。
  • 一句话心智模型：随机变量是"给结果贴数字标签"的函数；分布是这张标签背后"概率长什么样"。选对分布，比背公式更重要——因为每个分布描述的，是一种不同的"随机性是怎么产生的"。

一、故事引入：阿明想把"运气"称一称

阿明最近迷上了记账。但他发现，自己记的净是"今天手气好""今天背到家"这种废话。大刘拍拍他肩膀："你这哪叫记账，这是写日记。要想认真研究运气，得先把运气翻译成数字。"

"怎么翻？"阿明不服。

"比如抛硬币。"大刘掏出一枚，"规定：正面 = 1，反面 = 0。抛一次，结果就是一个数字 X，它要么是 1，要么是 0，没有第三种可能。这个 X，就叫随机变量——听着吓人，其实就是'把随机结果映射成数字的规则'。"

阿明眼睛亮了："那我抛 5 次、数一数出了几个正面，是不是又是一个随机变量？"

"对！"大刘点头，"那个数出来的正面个数，记作 Y，它可能是 0、1、2、3、4、5 里任意一个。Y 和刚才那个单次 X 不一样——X 只会蹦出 0 或 1，Y 能蹦出六个数。但更关键的是：Y 取每个数的'可能性大小'不是随便定的，它有一套固定的形状。"

"这套形状，就是分布？"

"聪明。"大刘笑了，"而真正有意思的是——世界上有那么几套'经典形状'，反复出现。认得它们，你就能一眼认出'眼前这个随机性，是哪种机制生出来的'。"

💡 一句话先记住：随机变量 = 给结果贴数字标签；分布 = 这套标签的概率长相。 今天我们就把最常用那几张"脸"认一认。

二、概念讲解

1. 随机变量：不是"变量"，是"函数"

严格说，随机变量 X 是一个从样本空间（所有可能结果）到实数集的函数：每个结果 ω，对应一个数字 X(ω)。

  • 离散型：取值能一个个数列出来（0/1、1–6、命中次数）。用"概率质量函数" P(X = k) 描述——直接列每个值的概率。
  • 连续型：取值铺满一段区间（身高、温度、等待时间）。单个数值的概率永远是 0，改用"概率密度函数"描述形状，靠"落在某区间"才算概率。
直觉坑：连续型里 P(X = 恰好 170.000…) = 0。这不代表"身高不可能是 170"，而是"精确到无穷小数位的那一个点"测度为 0。永远算区间，不算单点。

2. 几张最该认得的"脸"

① 伯努利分布（Bernoulli）——"一次 0/1 实验"

只做一次"成 / 败"实验。X = 1（成功）概率 p，X = 0 概率 1−p。

  • 例：抛一次硬币（p = 0.5）、一次投篮命中（p = 0.6）。
  • 期望 E[X] = p，方差 Var = p(1−p)。

② 二项分布（Binomial）——"n 次独立 0/1，数成功几次"

把 n 次独立的伯努利实验摞起来，数其中成功的次数。记作 X ~ B(n, p)。

  • P(X = k) = C(n, k) · pᵏ · (1−p)ⁿ⁻ᵏ（从 n 次里挑 k 次成功，乘各自概率）。
  • 期望 E = np，方差 Var = np(1−p)。
  • 例：投 10 次篮（命中率 0.6）恰好进 7 个；工厂抽 20 件查次品。

③ 均匀分布（Uniform）——"谁都别想特殊"

有限个结果，每个等可能。掷一颗公平骰子，X ∈ {1,2,3,4,5,6}，每个 P = 1/6。

  • 离散均匀：期望 = (最小+最大)/2（骰子 = 3.5）。
  • 连续均匀：落在任意等长区间的概率一样。

④ 泊松分布（Poisson）——"稀有事件在单位时间/空间里数个数"

用来数"某段时间或某片区域里，某种罕见事件发生了几次"。参数 λ = 平均发生率（单位时间里的期望次数）。记作 X ~ Poisson(λ)。

  • P(X = k) = e^(−λ) · λᵏ / k!。
  • 期望 = 方差 = λ（泊松的招牌特征：均值和方差相等）。
  • 例：客服中心每小时来电数、路口每月事故数、一本书每页的印刷错误数。
  • 它其实是二项分布的"极限瘦身版"：把一小时切成极多极短的小段，每小段最多发生 1 次、发生概率极小，合起来就逼近泊松（见题目 2）。

⑤ 正态分布（Normal）——"无数微小扰动叠出的钟形"

连续型，钟形曲线，参数μ（中心/均值）和 σ（胖瘦/标准差）。记作 X ~ N(μ, σ²)。

  • 经验法则（68–95–99.7）：约 68.3% 落在 μ±σ，约 95.4% 落在 μ±2σ，约 99.7% 落在 μ±3σ。
  • 它为什么无处不在？因为身高、测量误差这类量，是成千上万互不相干的微小因素（基因、营养、随机波动……）叠加的结果——这背后就是第 10 期要讲的中心极限定理。

3. 选对分布，比套公式更重要

一个常犯的错误：拿到数字就硬套正态。先问一句"这个随机性是怎么长出来的"：

  • 单次成败 → 伯努利；
  • 数 n 次里成功几次 → 二项；
  • 一堆等可能结果 → 均匀；
  • 数"罕见事件在某区间里发生了几次" → 泊松；
  • "一堆独立小因素叠加成的连续量" → 正态。

看清机制的人，永远不会把"每分钟路口事故数"拿正态去套。

💡 心法：随机变量负责"把世界翻译成数字"，分布负责"告诉这个数字长什么样"。今天这五张脸，记住每张对应的"剧情"，比记住五个公式有用十倍。

题目 1 · 伯努利与二项：阿明的投篮包

阿明三分命中率稳定在 0.6。某次训练他连投 5 球。

① 定义"单球命中"这个随机变量 X，写出它的分布（伯努利）和期望。
② 定义"5 球里命中的总个数" Y，它服从什么分布？参数 n、p 各是多少？
③ 算一算 P(Y = 3)（恰好进 3 个）是多少？给出组合数和概率表达式，并算出数值。
④ 这 5 球的平均命中数 E[Y] 是多少？方差呢？

题目 2 · 泊松：客服中心的来电

某客服热线平均每小时接到 4 个电话（λ = 4），且来电在时间上是"零散稀有"的。记 X = 接下来一小时内接到的电话数。

① X 该用哪个分布描述？为什么这里用泊松而不是二项/正态？
② 算 P(X = 0)（一小时内一个电话都没有）和 P(X = 2)。
③（进阶·机理）把一小时切成 240 个 15 秒小段，假设每段"最多来 1 个电话"、且来电话概率 p 很小使 240p = 4。先写出"用二项分布近似"的表达式，再说明 p→0、段数→∞ 时它如何收敛成泊松公式。这帮你理解"泊松到底从哪来"。

题目 3 · 正态：班级的身高钟形

某班男生身高近似服从正态分布 N(170, 5²)（单位：cm，μ = 170，σ = 5）。

① 用 68–95–99.7 经验法则，写出"身高落在 165–175""160–180""155–185"三个区间的大致概率。
② 身高超过 180 cm 的人，大约占多少？（提示：先想 160–180 覆盖了 95.4%，再看 180 之外怎么分）
③ 为什么"人的身高"会服从正态分布？把原因和"很多独立微小因素叠加"这件事连起来说一句。

题目 4 · 选脸练习：这三件事分别该套哪张脸？

判断下列说法对应的随机变量，该用今天哪一张"脸"（伯努利 / 二项 / 均匀 / 泊松 / 正态），并说出最关键的一个参数或理由：

① 掷一颗公平骰子出现的点数。
② 抽查 100 件产品，其中次品个数（单件次品率 2%）。
③ 某路口平均每月发生 0.5 起事故，问"本月事故数"的分布。
④（陷阱题）某APP"日活用户数"——有人说它正态、有人说它泊松，你倾向于哪个？理由是什么？

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1（伯努利 + 二项）：
  • ① X ~ Bernoulli(0.6)：P(X=1)=0.6，P(X=0)=0.4；E[X]=0.6。
  • ② Y ~ Binomial(n=5, p=0.6)。
  • ③ P(Y=3) = C(5,3)·(0.6)³·(0.4)² = 10 × 0.216 × 0.16 = 0.3456（约 34.6%）。
  • ④ E[Y] = np = 5×0.6 = 3；Var = np(1−p) = 5×0.6×0.4 = 1.2。
  • 题目 2（泊松）：
  • ① X ~ Poisson(λ=4)。理由：事件是"单位时间里的稀有计数"，且可拆成大量独立极小概率小段——正是泊松的剧情；正态是连续对称钟形、二项是固定 n 次成败，都不贴切。
  • ② P(X=0) = e^(−4) ≈ 0.0183（约 1.8%）；P(X=2) = e^(−4)·4²/2! = 8·e^(−4) ≈ 0.1465（约 14.7%）。
  • ③ 二项分布近似：把一小时分 240 段，每段来电概率 p = 4/240 = 1/60，则"一小时来电 k 个"≈ C(240,k)·pᵏ·(1−p)²⁴⁰⁻ᵏ。当段数 m→∞、p→0 且 mp=λ 固定时，C(m,k)pᵏ(1−p)ᵐ⁻ᵏ → e^(−λ)λᵏ/k!，即泊松。关键在于"每段最多 1 次 + 概率极小 + 段数极多"。
  • 题目 3（正态经验法则）：
  • ① 165–175（μ±σ）≈ 68.3%；160–180（μ±2σ）≈ 95.4%；155–185（μ±3σ）≈ 99.7%。
  • ② 180 之外 = 100% − 95.4% = 4.6%，正态左右对称，故 >180 占约 2.3%。
  • ③ 身高是成千上万互不相干的微小因素（遗传、营养、环境、随机发育扰动……）叠加的结果；每个单独影响都很小且大致独立，叠加后自然收敛成钟形——这正是中心极限定理的雏形。
  • 题目 4（选脸）：
  • ① 均匀（离散均匀，6 个等可能结果）。
  • ② 二项（n=100, p=0.02，数次品个数）；若 n 很大 p 很小也可近似泊松(λ=2)，但"机制"上它是固定 100 次成败，标答是二项。
  • ③ 泊松（λ=0.5，月度稀有事件计数）。
  • ④ 倾向泊松（或其连续化亲戚）：日活是"单位时间里发生的独立事件计数"，属于稀有/可数事件叠加的剧情；正态适合"连续量由大量微小扰动叠加"，而用户到达本质是计数。这是个好辩论题，言之成理即可，但机制上泊松更贴切。
