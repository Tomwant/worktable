每日概率学 · 第 8 期

  • 日期：2026-10-02（周五）
  • 今日概念：蒙特霍尔问题（Monty Hall Problem）——三扇门后一辆车、两只羊；你选中一扇后，主持人故意打开一扇"羊门"，问你"换不换？" 正确答案是：换门，胜率从 1/3 直接翻倍到 2/3。
  • 一句话心智模型：主持人的"故意"才是关键。他不是随机开门，而是用"绝不打开车"的动作，把那 2/3 的"你一开始选错"的概率，整个儿压到了剩下的那扇门上。

一、故事引入：幸运之门的抉择

综艺《幸运之门》录音棚里，主持人老蒙笑眯眯地站在一排三扇关着的门后。"一号、二号、三号，"他敲着门板，"其中一扇后面是辆新车，另外两扇后面是——咩。"两只羊。

阿明被请上台，心跳加速。他选了一号门。

老蒙没有立刻揭晓。他眨眨眼："按规则，我要打开一扇你没选的、而且后面是羊的门。"他把手放在三号门上，推开——咩，一只羊。

然后老蒙转身对着阿明，戏谑地扬眉："现在剩下一号和二号。你要坚持一号，还是换成二号？"

阿明脑子飞转：两扇门，一车一羊，那不就是五五开？换不换都一半一半。"不换了，就一号。"他心想。

台下的大刘急得直拍大腿："换啊笨蛋！换了有 2/3！"

"胡说，"阿明不服，"现在就两扇门，凭什么换的就 2/3？"

老蒙摊手："统计学上，大刘是对的。你刚才那一下'五五开'的直觉，恰恰是全人类都会掉进去的坑。"

💡 这就是蒙特霍尔问题：结论反直觉到当年《纽约时报》专栏作家玛丽莲·沃斯·萨凡特在报纸上给出"换门胜率 2/3"的答案后，收到上万封读者来信骂她错，其中好几千封署名"我拥有数学/统计学博士学位"。

二、概念讲解

1. 为什么"两扇门 = 1/2"是错的

你选一号门那一刻，车在一号门后的概率就是 1/3，这个概率不会因为之后发生任何事而自动变成 1/2。

主持人打开三号门（羊），这个动作改变的不是"车在哪"，而是把信息重新分配了：

  • 如果车真的在一号（你选对了，概率 1/3）：老蒙随便开二或三号都行（都是羊）。此时换门 → 你换到的是羊，输。
  • 如果车在二号（概率 1/3）：老蒙只能开三号（不能开有车的二号），于是换门 → 赢。
  • 如果车在三号（概率 1/3）：老蒙只能开二号，于是剩下的是二号车，换门 → 赢。

注意后两种情况（车在二或三，合计 2/3）：只要你的初始选择是错的（占了 2/3 的可能），老蒙"避开车"的开门动作就唯一确定了另一扇有车的门。换成那扇，必赢。

所以：换门胜率 = 你一开始选错的概率 = 2/3；不换胜率 = 你一开始选对的概率 = 1/3。

2. 核心：主持人的"故意"不是随机

把主持人换成"瞎子随机开门"就不一样了（见题目 3）。老蒙的精髓在于——他永远不开出车。这个"永远不"是有信息的：它等于在告诉你"我替你把另外两扇门里的羊排除掉了一扇，剩下那扇独吞了原本两扇门合计的 2/3"。

一句话：那 2/3 一开始均匀躺在"你没选的两扇门"上；老蒙揭开一扇羊门，等于把这两扇门里的 2/3 全浓缩进了剩下那唯一一扇。 你的一号门，自始至终只守着它最初那 1/3。

3. 一个"作弊"的直觉放大器：100 扇门

把门加到 100 扇，1 车 99 羊。你选 1 号（中车概率 1/100）。老蒙接着打开 98 扇羊门，最后只剩你选的 1 号和另一扇，问你换不换。

这时你还觉得"剩下两扇五五开"吗？你当初瞎蒙中那 1 辆车的概率只有 1%，那 99% 的"车在别处"被老蒙一步步压到了最后一扇门上。换，就是 99%。

三扇门只是这个数字游戏最收敛的版本——1/3 和 2/3 的差距不够夸张，才显得反直觉。

4. 用条件概率 / 贝叶斯语言重述（呼应第 2 期）

设 A = "一号门有车"，B = "老蒙开三号且为羊"。

  • P(A) = 1/3。
  • P(开三号 | A) = 1/2（A 成立时二、三号都是羊，随机二选一）。
  • P(开三号 | 非A)：若车在二号，老蒙必开三号 → 概率 1；若车在三号，老蒙必开二号 → 概率 0。非A 下"车在二或三"各 1/2，故 P(开三号 | 非A) = 1/2·1 + 1/2·0 = 1/2。
  • 于是 P(A | 开三号) = P(A)P(开三号|A) / [P(A)P(开三号|A) + P(非A)P(开三号|非A)]

= (1/3 · 1/2) / [(1/3 · 1/2) + (2/3 · 1/2)] = (1/6) / (1/2) = 1/3。

所以给定"老蒙开了三号（羊）"，一号门仍有车的概率仍是 1/3，那二号门因此有车的概率 = 1 − 1/3 = 2/3。换门赢。

💡 心法："两扇门剩下来"不等于"概率各 1/2"。概率属于'门'，也属于'主持人那个避开车的信息动作'。一旦你把主持人的行为当成有信息量的条件，1/3 和 2/3 自然就分出来了。

三、代表性题目 / 故事（请你来总结 ✍️）

请试着回答：① 换门 / 不换，各自的胜率到底是多少？② 关键在主持人的"故意"还是"随机"？③ 把门数放大，直觉怎么变？

题目 1 · 经典三扇门

回到阿明的局面：你选一号，老蒙开三号（羊）。

① 若你坚持不换，获胜概率是多少？若你换成二号，获胜概率是多少？分别给出理由，而不是只写数字。
② 用一句话反驳"剩下两扇门，所以各 1/2"这个直觉。
③ 把"换门赢"的情形画成三种初始情况（车在一/二/三号）逐一核对，说明为什么是 2/3。

题目 2 · 100 扇门的极端版

综艺升级：100 扇门，1 车 99 羊。你随手选 1 号，老蒙依次打开 98 扇羊门，最后只剩 1 号和另一扇（比如 57 号）。

① 此时不换和换到 57 号，胜率各是多少？
② 为什么门数越多，"换门更优"反而越显得理所当然？这反过来帮你想通了三扇门版吗？
③（进阶）如果门数变成 N 扇（1 车 N−1 羊），换门胜率的通项公式是什么？当 N→∞ 时趋近于多少？

题目 3 · 主持人是个"瞎子"（关键反例）

这次换了新主持人小盲：他不知道车在哪，只是从你没选的两扇门里随机推开一扇。恰好，他推开的是羊。

① 在这种"随机开门且恰好是羊"的前提下，换门的胜率还是 2/3 吗？还是变成了 1/2？请用条件概率或分情况枚举算一算。
② 这个反例说明了什么？为什么"主持人知不知道车在哪"这么要命？
③ 把它和第 2 期的贝叶斯思想连起来：主持人的"知识"到底往条件概率里注入了什么信息？

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1：
  • 不换胜率 = 初始选对的概率 = 1/3；换门胜率 = 初始选错的概率 = 2/3。
  • 反驳"1/2"：剩下两扇门没错，但它们不是对称地各分 1/2——你最初那扇门的概率自选中起就被钉死在 1/3，主持人的行为只重新分配"另外两扇门"里的 2/3，没动过你那扇。
  • 三种情况核查：车在一号→不换赢/换输；车在二号→老蒙只能开三号→换到二号赢；车在三号→老蒙只能开二号→换到二号赢。三情等可能，换门赢两况，故 2/3。
  • 题目 2：
  • 不换 = 1/100；换到 57 号 = 99/100。
  • 直觉：门越多，你"瞎蒙中"的概率越低（1/N），那 1−1/N 的概率被主持人一步步压到最后一扇门，"换"几乎是捡漏。三扇门只是最收敛版本，差距不够刺激才反直觉。
  • 通项：N 扇门，换门胜率 = (N−1)/N。N→∞ 时趋近于 1（必然赢）。
  • 题目 3（关键反例）：
  • 此时换门胜率 = 1/2，不再有优势。
  • 分情况：你选对车（1/3）时，另两扇都是羊，小盲随机开门必是羊（概率 1）；你选错（2/3）时，另两扇一车一羊，小盲随机开门恰好是羊的概率 1/2。
  • "小盲开门且为羊"的总概率 = (1/3)(1) + (2/3)(1/2) = 2/3。
  • 在该前提下"你当初选对"的概率 = (1/3 · 1) ÷ (2/3) = 1/2。于是换不换一样，各 1/2。
  • 说明了：蒙特霍尔的 2/3 完全依赖主持人"绝不打开车"这个有信息量的动作。一旦主持人变瞎、开门随机，他那个动作就不再携带"车在哪儿"的信息，问题退化成普通的二选一。
  • 贝叶斯视角：主持人的"知识"把"他开哪扇门"变成了一个依赖于车位置的非均匀事件；正是这个非均匀（条件概率不对称），才让后验里"换门"跳到 2/3。瞎子主持人的开门事件与车位置近似独立，后验就塌回 1/2。
