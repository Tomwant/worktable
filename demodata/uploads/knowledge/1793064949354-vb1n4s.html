第 4 期 · 随机梯度下降（SGD）：用噪声逼出最优解

今日概念：随机梯度下降 Stochastic Gradient Descent（SGD）
一句话：要找一个巨大山谷的最低点，不必每次都量遍所有地形——随手抓一小撮样本估个方向，边走边改，噪声反而帮你跳出假坑。

一、故事：阿明的"下山省力气"难题

阿明开了家外卖配送公司，手里几千万条历史订单，想训练一个模型预测"某区域某时段该派几名骑手"。他要找的，是让预测误差最小的那组参数 θ（一个山谷的最低点）。

  • 老办法（全批量梯度下降）：每走一步，都拿全部几千万条订单算一次"该往哪走"，方向极准，但一步就要十几分钟，模型还没训完竞争对手就上市了。
  • 大刘的损招（SGD）：每步只随机抽一小批（比如 32 条）订单估方向。方向抖、有噪声，但一步 0.1 秒。走十万步下来，反而先到了谷底附近，还顺手绕开了几个假的最低点（浅坑）。

阿明一开始嫌"这方向乱跳，能靠谱吗？"大刘笑："噪声不是 bug，是 feature——它让你不会卡在第一个小坑里；而且抽得越多越准，最后自然安静下来。"

二、概念讲解

1. 它在优化什么

我们要最小化期望风险 L(θ) = 𝔼_ξ[ℓ(θ; ξ)]，其中 ξ 是一条随机样本（一笔订单），ℓ 是单样本损失。

  • 全批量梯度：G(θ) = ∇L(θ) = (1/n) Σᵢ ∇ℓ(θ; ξᵢ) —— 算全部 n 条样本。
  • SGD 梯度估计：随机抽一个（或一小批 b 个）样本，用 g(θ) = (1/b) Σⱼ ∇ℓ(θ; ξᵢⱼ) 当方向。

2. 为什么"噪声"能用——它是无偏估计

核心公式：𝔼[g(θ)] = G(θ)

每个样本梯度都是"真梯度"的一个无偏样本，平均回去就是真值。这直接接上第 9 期（随机变量期望）和第 15 期（蒙特卡洛：把难算量当样本均值逼近）。

方差才是代价：单样本估计的方差是 σ²；抽 b 个取平均，方差降到 σ²/b（标准误 = σ/√b，闭环第 10 期 CLT）。批量越大越稳，但越慢——这就是 SGD 的根本权衡。

3. 学习率 η：步长 = 探索/利用的"温度"

η 太大→在谷底乱蹦停不下来；η 太小→半天挪不动。它被戏称为"温度"，和第 3 期模拟退火的退火温度同构：大 η 像高温乱撞（能跳出局部极小），小 η 像低温精细收敛。

收敛的黄金条件（Robbins–Monro，1951）：

  • Σ ηₜ = ∞（步子总和要够大，才走得够远）
  • Σ ηₜ² < ∞（单步噪声要被"平均掉"，否则永远抖）

经典解：ηₜ = c/t。

4. 它本质是个随机过程

  • SGD 的迭代序列 {θₜ} 是一条马尔可夫链（第 12 期）——下一步只取决于当前 θₜ 和新抽到的样本。
  • 接近最优解时，步子退化为带收缩的随机游走（第 14 期）：θ 在 θ* 附近 ±噪声地板 抖动。
  • 这些抖动的分布近似正态（第 10 期 CLT）。
  • 想把它从"优化"升级成"采样后验"？给梯度里再加固定温度噪声 → 第 5 期要讲的 SGLD（接第 16 期熵）。

5. 关键直觉（背下来）

  • 批量 b 越大 → 方差 σ²/b 越小 → 越稳但越慢。
  • 学习率 η 太小 → 慢；η 太大 → 永远震荡停不准。
  • 末段噪声地板 ≈ η·σ：想更准就调小 η，但要付出变慢的代价（学习率的偏差–方差权衡）。
  • 应用版图：深度学习训练、大规模推荐/搜索、在线学习、强化学习策略优化。

三、四道代表性题目（你先总结，答案在第四节）

题 1 · 无偏估计基本功
设 4 个样本在某 θ 处的单样本梯度分别为 2、0、−1、1。
(a) 全批量梯度 G 是多少？
(b) 若每步随机抽 1 个样本当 g，验证 𝔼[g] = G，并算 Var(g)。
(c) 若每步抽 2 个（有放回取平均）当 g，Var 变为多少？
题 2 · 学习率衰减选择题
下列三种 ηₜ 中，哪些满足 Robbins–Monro 收敛条件（Σηₜ=∞ 且 Σηₜ²<∞）？
(A) ηₜ = 1/t　(B) ηₜ = 1/√t　(C) ηₜ = 0.1（常数）
不满足的会出什么毛病？
题 3 · 手算一次 SGD 轨迹
最小化 f(θ) = (θ − 2)²。用单样本 SGD：每步抽一个"观察点"(x=1, y=2)，梯度近似为 2·1·(θ·1 − 2) = 2(θ − 2)，更新 θ ← θ − η·2(θ−2)，η = 0.1。
从 θ₀ = 0 出发，写出 θ₁、θ₂、θ₃，并说它最终趋向哪。
题 4 · 噪声地板与学习率权衡（闭环模拟退火）
在最优解 θ* 附近，模型曲率 H>0，真实梯度 ≈ H(θ − θ*)，每步还叠零均值噪声 εₜ（方差 σ²）。更新 θ ← θ − η[H(θ−θ*) + ε]。
(a) 忽略噪声时，θ 以多快速度收敛到 θ*？（收缩因子？）
(b) 加上噪声后，θ 会在 θ* 附近维持多大范围的"永久抖动"？它随 η 怎么变？
(c) 这和第 3 期模拟退火的"温度太高冻不进谷底 / 温度太低冻结在局部"有何对应？

四、完整解题思路（含答案）

题 1 答案
(a) G = (2 + 0 − 1 + 1) / 4 = 0.5。
(b) 抽样均匀，𝔼[g] = (2+0−1+1)/4 = 0.5 = G ✓（无偏）。
　　𝔼[g²] = (4+0+1+1)/4 = 1.5，Var(g) = 1.5 − 0.5² = 1.25。
(c) 抽 2 个取平均，方差降为原来的 1/2：Var = 1.25 / 2 = 0.625。
　　→ 印证"批量 b 越大方差越小"，单样本(σ²=1.25) 到 双样本(0.625) 减半。
题 2 答案
(A) ηₜ=1/t：Σ1/t = ∞（调和级数发散），Σ1/t² < ∞（收敛）→ 满足，a.s. 收敛 ✓。
(B) ηₜ=1/√t：Σ1/√t = ∞，但 Σ(1/√t)² = Σ1/t = ∞ → 第二个条件不满足，不保证 a.s. 收敛（只能"平均后"收敛）。
(C) ηₜ=0.1 常数：Σ=∞，Ση²=∞ → 不满足，噪声永不被平均，θ 在 θ* 附近以固定幅度永久抖动，停不准。
口诀：要"走得够远"又要"抖得净"，1/t 两全，常数步长只满足前者。
题 3 答案
梯度 = 2(θ − 2)，更新 θ ← θ − 0.1·2(θ − 2) = θ − 0.2(θ−2) = 0.8θ + 0.4。
- θ₀ = 0
- θ₁ = 0.8·0 + 0.4 = 0.4
- θ₂ = 0.8·0.4 + 0.4 = 0.32 + 0.4 = 0.72
- θ₃ = 0.8·0.72 + 0.4 = 0.576 + 0.4 = 0.976
递推 θₜ = 0.8θₜ₋₁ + 0.4，不动点 θ* 满足 θ* = 0.8θ* + 0.4 → 0.2θ* = 0.4 → θ* = 2。
即逐步逼近真实最小值点 θ=2（每步保留 0.8、补回 0.4），无噪声时严格收敛。
题 4 答案
(a) 忽略噪声：θₜ₊₁ − θ* = (1 − ηH)(θₜ − θ*)，收缩因子 1 − ηH（要求 0<ηH<2 才稳定）。
(b) 加噪声：稳态方差 ≈ η²σ² / [1 − (1−ηH)²] ≈ ησ²/(2H)（小 η 近似）。即永久抖动幅度 ∝ η：η 减半，噪声地板约减半，但收敛变慢——这正是学习率的偏差–方差权衡。
(c) 对应模拟退火：η 像"温度"。η 太大=温度太高，永远在谷里蹦（冻不进谷底）；η 太小=温度太低，可能在浅坑（局部极小）里冻结出不来。两者都要靠先大后小的退火式调度平衡——SGD 的 1/t 衰减，正是退火的数学版。

第 5 期 · 随机梯度朗之万动力学（SGLD）：给 SGD 加噪声，从"优化"变"采样"

  • 把第 4 期 SGD 的学习率 reinterpret 成"温度"，再注入固定高斯噪声，迭代就不再是找最低点，而是从模型的后验分布里抽样——优化器秒变 MCMC 采样器（闭环第 15 期蒙特卡洛、第 16 期熵/温度）。
