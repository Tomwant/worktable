  • 今日概念：独立事件与互斥事件（Independent vs. Mutually Exclusive）——"互不影响"和"不可能同时发生"，别再傻傻分不清
  • 一句话心智模型：互斥看"能不能同时发生"，独立看"一个发生会不会改变另一个的概率"。这俩几乎相反，不是一回事。

一、故事引入：年会抽奖的两张券

阿珍在年会上抽到了两张抽奖券：一张红券（左边口袋），一张蓝券（右边口袋）。

主持人宣布规则：

"红券中奖概率 1/10，蓝券中奖概率 1/10。两张券由两台独立的抽奖机分别摇号，互不影响。"

所以——红券中不中，完全不改变蓝券中奖的几率。这就是独立：两件事各过各的，谁也不"传染"谁。

但主持人又补了一句：

"不过今年公司只设了一个一等奖，红蓝两券共用这唯一名额——两张不可能同时中一等奖。"

这就出现了互斥（对"中一等奖"而言）：红券中了一等奖，蓝券就铁定没中。

同事大刘嘀咕："既然红蓝独立、各 1/10，那两张都中的概率就是 1/100 呗？"

主持人笑了："错。一等奖就一个坑，两张根本不可能同时中。你说的'独立'在'中一等奖'这件事上根本不成立——除非把红蓝当成两个不同奖项的抽奖。"

这时阿珍抛出那个最反直觉的问题：

"那……互斥的事件，是不是就独立呢？"

主持人摇摇头，写下关键结论：

如果两个事件互斥，且各自都有发生的可能（概率 > 0），那它们一定不独立。

因为——一旦其中一个发生了，另一个就绝对不可能发生，它的概率直接从 P(B) 掉到了 0。一个事件的发生"狠狠改变了"另一个的概率，这正是"不独立"的极端表现。

所以互斥和独立，非但不是一回事，往往还恰恰相反。

二、概念讲解

1. 互斥事件（Mutually Exclusive / Disjoint）

  • 定义：A 和 B 不能同时发生，即 A∩B = ∅，等价于 P(A∩B) = 0。
  • 直觉：一个发生，另一个必不发生。
  • 例子：掷一颗骰子，"出 1 点"和"出 6 点"互斥。

2. 独立事件（Independent）

  • 定义：一个发生不影响另一个发生的概率，即 P(A∩B) = P(A)·P(B)；等价地，当 P(A)>0 时 P(B|A) = P(B)。
  • 直觉：知道 A 发生了，B 的概率纹丝不动。
  • 例子：抛硬币两次，第一次正面朝上不影响第二次。

3. 最容易踩的坑（本期重中之重）

| 误区 | 真相 |

| --- | --- |

| "互斥 = 独立" | ❌ 互斥（概率都>0）必然不独立，二者几乎相反 |

| "独立 = 互斥" | ❌ 独立（概率都>0）必然不互斥，因为 P(A∩B)=P(A)P(B)>0，能同时发生 |

| 既互斥又独立 | 只有一种情况：其中至少一个事件概率为 0 |

还有一个计算上的实用区分：

  • 求"至少一个发生" P(A∪B)：
  • 互斥时直接相加：P(A∪B) = P(A) + P(B)
  • 独立时用容斥：P(A∪B) = P(A) + P(B) − P(A)P(B)

💡 一句话心法：互斥是"空间不重叠"，独立是"信息不相关"。拿"能不能同时发生"问一句，就分清了互斥；再问"知道了会不会变"，就分清了独立。

三、代表性题目 / 故事（请你来总结 ✍️）

请试着对每道题写出：① 是互斥吗？② 是独立吗？③ 你的关键判断依据；④ P(A∩B) 或 P(A∪B) 的值。

题目 1 · 硬币与骰子

抛一枚公平硬币，同时掷一颗公平六面骰。

  • 事件 A：硬币正面朝上。
  • 事件 B：骰子点数为偶数（2 / 4 / 6）。
A 和 B 独立吗？互斥吗？P(A∩B) 是多少？

题目 2 · 一班里的两个代表

某班 30 人：12 名女生、18 名男生。随机抽签选一人当"今日值日"。

  • 事件 A：抽到的人是女生。
  • 事件 B：抽到的人是男生。
A 和 B 互斥吗？独立吗？从中体会"为什么互斥的事件反而不独立"。

题目 3 · 手机的双故障（综合）

某型号手机：屏幕损坏概率 0.05，电池故障概率 0.04，且两故障相互独立。

  • （甲） 求"屏幕和电池同时出故障"的概率。
  • （乙） 求"至少一处出故障"的概率。
  • （丙） 把事件改为"屏幕损坏"(A) 与"整机完全正常"(即屏幕和电池都好，¬A∩¬B)。问：A 与"整机正常"互斥吗？独立吗？

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1：硬币与骰子来自不同随机源，互不影响 → 独立。能否同时发生？能（正面且偶数点）→ 不互斥。P(A∩B) = P(A)P(B) = 1/2 × 1/2 = 1/4。
  • 心法：独立不代表"分开发生"，恰恰可以"一起发生"。
  • 题目 2：抽到的人不可能既是女又是男 → 互斥（P(A∩B)=0）。但独立要求 P(A∩B)=P(A)P(B)=12/30×18/30≠0，矛盾 → 不独立。
  • 心法：互斥的事件其实是"强相关"——一个发生，另一个必定不发生。
  • 题目 3：
  • 甲 = 0.05 × 0.04 = 0.002（独立直接相乘）；
  • 乙 = 1 − (1−0.05)(1−0.04) = 1 − 0.95×0.96 = 1 − 0.912 = 0.088；
  • 丙：A（屏幕坏）与"整机正常"（屏幕电池都好）不能同时发生 → 互斥；且两者概率都 >0 → 不独立。
