第 1 期 · 随机图与渗流：六度分隔与"突然连通"的相变

本期概念：随机图（Erdős–Rényi 模型） 与 渗流（Percolation）。
核心直觉——连接是"相变"出来的：边数跨过一条看不见的临界线，系统会从一个个孤立小圈子，瞬间熔成一张覆盖全局的巨网。疾病能不能蔓延、互联网抗不抗揍、你和陌生人隔几步，全由这条线决定。

一、故事引入：阿明的"朋友圈突然连通"之谜

阿明把母校 1000 名毕业生拉进一个群，想看看大家私下还聊不聊得来。他做了一件简单的事：把每个人当作一个节点，对任意两个人，都以同一个小概率 p 随机连一条"好友边"。这就是数学家 Erdős 和 Rényi 在 1959 年定义的随机图 G(n, p)——n 个人，p 是每条边存在的独立概率。

阿明先试了 p = 0.0008（平均每人约 0.8 个好友）。点开可视化：群被切成几百个互不连通的小圈子，最大的那坨也才 7、8 个人，像一地碎玻璃。

大刘在旁边说："你把概率翻倍试试？多这么一丁点边，能有多大区别。"

阿明把 p 调到 0.0015（平均每人 1.5 个好友）。再一看——最大的圈子突然吞掉了 580 人，超过总人数的一半。从 0.8 到 1.5，平均好友数只多了 0.7，却从"七零八落"跳到了"一呼百应"。

"这不科学，"大刘瞪眼，"加几条边而已，怎么像开水一样'咕咚'一下就沸了？"

阿明笑了："这叫相变（phase transition）。随机图里藏着一条临界线——平均度 ⟨k⟩ = 1。线这边是一地碎玻璃，线那边是瞬间熔成的一片海。临界点附近，系统对参数极度敏感，这正是概率里最反直觉、也最迷人的地方。"

后来大刘做了个公共卫生的课题：怎么用"消毒、戴口罩"把传染链掐断？阿明说："你那张接触网，本质就是一张随机图；病毒沿着边'渗流'。只要把每条边的'有效传染概率'压到临界值以下，病就渗不过去——渗流不发生，大暴发就不可能。"

二、概念讲解

2.1 随机图 G(n, p)：从"撒边"说起

  • 节点：n 个（人、网页、城市……）。
  • 边：C(n, 2) 条可能的边，每条独立地以概率 p 出现。
  • 平均度（average degree）：⟨k⟩ = p · (n − 1) ≈ p·n。这是整张图的"平均每个节点的朋友数"，是后面一切的旋钮。

直觉钩子：如果 ⟨k⟩ 很小，绝大多数边没出现，图必然是碎的；⟨k⟩ 变大，边越来越多——但不是线性地"慢慢连通"，而是越过某点后"哗"地连通。

2.2 平均度与两条临界线（相变）

随机图最漂亮的发现，是存在两条由平均度刻画的临界线：

| 平均度 ⟨k⟩ | 现象 | 直觉 |

|---|---|---|

| ⟨k⟩ < 1 | 没有巨无霸分量，最大圈子约 ln n 大小 | 边太少，连不成片 |

| ⟨k⟩ = 1 | 巨型分量诞生的临界点 | 相变点 |

| ⟨k⟩ > 1 | 出现占整体比例 S > 0 的巨连通分量（giant component），S ≈ 1 − e^{−⟨k⟩S} | 突然熔成一片海 |

| ⟨k⟩ ≈ ln n | 整张图几乎一定全连通（任意两点可达） | 彻底连成一张网 |

  • 巨分量阈值 p ≈ 1/n（对应 ⟨k⟩ ≈ 1）：跨过它，才出现覆盖常数比例人群的"大圈子"。
  • 连通阈值 p ≈ (ln n)/n（对应 ⟨k⟩ ≈ ln n）：跨过它，连最边缘的孤点都被拉进网里。
  • 两条线相差约 ln n 倍——对大网络来说这是个巨大的鸿沟。
为什么叫"相变"？ 就像水加热到 100°C 从液态"突变"成气态，随机图在 ⟨k⟩ = 1 处，连通性从"碎"到"巨"地跳变。参数只动一点点，宏观性质天翻地覆。这正是大刘"加几条边就沸了"的困惑之源。

2.3 六度分隔：为什么巨网并不"远"

巨网出现后，另一个反直觉的事实是——它并不"大"到走不到。

在 G(n, p) 里，任意两点间的最短距离（直径）约为：

```

d ≈ ln n / ln ⟨k⟩

```

这是对数级增长：网络规模翻 1000 倍，平均距离只翻约 3 倍。1967 年 Milgram 的实验发现，任意两个美国人平均只隔 约 6 步——这就是著名的六度分隔（six degrees of separation）。

直觉：你朋友的朋友的朋友……每跳一层，人数按 ⟨k⟩ 倍爆炸（≈ 50 倍），几跳就覆盖全人类。所以"世界很小"不是鸡汤，是随机图的数学结论。

2.4 渗流：消毒能否阻断传染链

渗流（percolation） 是随机图在"格子"上的表亲：在方格/网络上，每条边（或每个点）以概率 p 打开（可通行），否则关闭。

  • p < p_c（临界概率）：只存在有限大小的连通簇，流体/病毒渗不过整张网 → 渗流不发生。
  • p > p_c：出现无限大的连通簇 → 渗流发生，病毒可跨网暴发。
  • 经典值：二维方格 bond percolation 的 p_c = 1/2。

这恰好是传染病模型的本质：把接触边当作"可传染边"，每条边有效传染概率为 q。在随机图(mean-field)近似下，大暴发发生的条件等价于 ⟨k⟩·q > 1——也就是 基本再生数 R₀ > 1。要阻断，就把 q 压到 1/⟨k⟩ 以下：要么少接触（降 p，社交距离），要么降每条边传染率（口罩、疫苗）。

闭环回顾：第 5 期"期望值"、第 10 期"中心极限定理"、第 14 期"随机游走"、第 19 期"重尾"——它们都默认"系统平滑可近似"。而今天这张图告诉你：有些系统天生有临界点，平滑思维会彻底失灵。

三、代表性题目 / 故事（你来总结）

下面四题，先别急着看答案，自己推一遍——把"临界线"和"对数直径"两个直觉用进去。

题目 1 · 朋友圈爆发

某 App 有 n = 1000 个用户，按 G(n, p) 随机连好友。

  • (a) 当平均度 ⟨k⟩ = 0.8 时，最大的朋友圈大概多少人？
  • (b) 当平均度 ⟨k⟩ = 1.5 时，最大的朋友圈占全体的比例约多少？

题目 2 · 连通阈值

一个 n = 10⁶ 用户的社交网络，想让"任意两人几乎一定能互加好友链"成立，p 至少要多大？此时平均每人要连多少个好友？对比"出现巨分量"的阈值差多少倍？

题目 3 · 六度验证

全球 n = 80 亿 人，按平均度 ⟨k⟩ = 50 的随机图建模。任意两人之间的平均距离约几步？这和"六度分隔"对得上吗？

题目 4 · 消毒阻断传染

某社区平均每人每天有 ⟨k⟩ = 20 次有效接触。每次接触传播病毒的真实概率（戴口罩前）为 q。

  • (a) 大暴发（出现覆盖全社区的传染网）发生的临界 q_c 是多少？
  • (b) 若通过戴口罩、消毒把每条边的传染率降到 q = 0.03，能否阻断大暴发？需要再把接触次数压到多少以下（或 q 再降到多少）才稳？

四、解题思路（参考答案，写全供你对照）

题目 1 · 朋友圈爆发

思路：直接看平均度与临界线 ⟨k⟩ = 1 的关系。

  • (a) ⟨k⟩ = 0.8 < 1：处于"碎玻璃"区。理论上最大连通分量大小约 ln n = ln(1000) ≈ 6.9，即约 7 人（占 0.7%）。其余全是两三人小圈。
  • (b) ⟨k⟩ = 1.5 > 1：出现巨分量，其比例 S 满足自洽方程 S = 1 − e^{−⟨k⟩S}。

代入 ⟨k⟩ = 1.5：试 S = 0.58 → 右边 = 1 − e^{−0.87} ≈ 1 − 0.419 = 0.581；S ≈ 0.58 收敛。

所以最大圈子约占 58%，即约 580 人。

  • 结论：平均好友数从 0.8 涨到 1.5（仅 +0.7），最大圈子从 7 人飙到 580 人——相变的力量。

题目 2 · 连通阈值

思路：连通阈值 p ≈ (ln n)/n，巨分量阈值 p ≈ 1/n。

  • ln(10⁶) = 13.8155，故 p ≈ 13.8155 / 10⁶ ≈ 1.38 × 10⁻⁵。
  • 此时平均度 ⟨k⟩ ≈ p·n = ln n ≈ 13.8——即每人平均要连 约 14 个好友，整图才几乎一定全连通。
  • 对比巨分量阈值 p ≈ 1/n = 10⁻⁶，平均度仅 1。两者相差 ln n ≈ 13.8 倍：从"出现大圈子"到"彻底连成一片"，中间还差一个数量级的边。

题目 3 · 六度验证

思路：用直径公式 d ≈ ln n / ln ⟨k⟩。

  • ln(8×10⁹) = ln 8 + ln 10⁹ ≈ 2.079 + 20.723 = 22.802。
  • ln 50 ≈ 3.912。
  • d ≈ 22.802 / 3.912 ≈ 5.83 → 约 6 步。
  • 与 Milgram 的"六度分隔"惊人吻合——说明真实社交网在"平均距离"这一点上，和随机图模型高度一致。

题目 4 · 消毒阻断传染

思路：大暴发 ⟺ 渗流发生 ⟺ R₀ = ⟨k⟩·q > 1，临界 q_c = 1/⟨k⟩。

  • (a) ⟨k⟩ = 20 → q_c = 1/20 = 0.05。即每条接触传染率超过 5%，就会暴发。
  • (b) q = 0.03 < 0.05 → R₀ = 20 × 0.03 = 0.6 < 1，能阻断大暴发（传染网渗不过去）。

若想更稳（冗余），可把接触数压到 ⟨k⟩ < 1/q = 33.3（其实已满足）；或把 q 再降到比如 0.02（R₀ = 0.4）。

  • 政策直觉：阻断大暴发不用把 q 降到 0，只要压到 1/⟨k⟩ 这条临界线之下——这就是"社交距离 + 口罩"的数学底线。
