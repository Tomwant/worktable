第 13 期 · 策略梯度与 REINFORCE / Actor-Critic

一句话：当动作空间大到装不下、甚至连续不断，与其先估价值再反推动作，不如直接把"策略"训成一个会爬坡的神经网络。

一、故事：方向盘转多少度，你没法查表

阿明的取餐机器人第 12 期总算用 DQN（第 12 期）背下了大商场的 Q 表——但该机器人现在换了个更难的任务：它是一台真车，要控制方向盘转角。

大刘让阿明试试："你让 DQN 选个动作。"

阿明愣了："转角是从 −π 到 π 的连续值，Q 表怎么枚举？离散成 360 格？那 0.5 度和 0.6 度中间的精细动作就丢了，而且 argmax 只能吐一个确定角度，可有些路口最优策略明明是'八成向左、两成向右'的随机打法。"

大刘点点头："所以别绕弯子了——你之前第 10、11、12 期都在学'某个状态下每个动作值多少'（价值 / Q 函数），再反推动作。这条路在离散有限动作时很香，但碰上连续动作和随机策略就卡壳。直接把策略 π_θ(a|s) 参数化成神经网络，用梯度上升去抬高它的期望回报。让策略自己长腿，自己学会'在该状态下该往哪使劲'。"

这一期，我们讲策略梯度这条"直接优化策略"的主线，以及它的两个亲儿子：REINFORCE（最朴素的蒙特卡洛版）和 Actor-Critic（边走边评、低方差版）。

二、概念：直接优化策略

1. 为什么不让策略自己长腿

回顾这条 RL 主线：第 9 期 多臂老虎机（探索-利用）→ 第 10 期 MDP 与贝尔曼方程（价值函数）→ 第 11 期 TD 与 Q 学习（价值法、离策略）→ 第 12 期 DQN（价值法 + 函数近似）。我们一直在学"价值"，再用 argmax 反推动作。它的两个硬伤：

  • 连续动作装不下：方向盘转角、机械臂力矩都是连续的，Q 表无法枚举；离散化既丢精度，又卡不住 argmax。
  • 随机策略难表达：最优解有时本身就是"以某概率分布撒动作"，argmax 只能给一个确定动作，表达不了"随机"。

策略梯度绕开这两点：直接建模 π_θ(a|s)，再优化它。

2. 策略梯度的核心公式

目标：最大化期望回报 J(θ) = E_{τ∼π_θ}[ G(τ) ]，τ 是整条轨迹。策略梯度定理给出：

```

∇_θ J(θ) = E_{τ∼π_θ}[ Σ_t ∇_θ log π_θ(a_t|s_t) · G_t ]

```

三个读点：

  • 对数导数技巧（似然比）：∇π / π = ∇logπ，把"改参数如何让某个动作更可能"转成"对数概率的梯度"，天然不依赖环境模型 P。
  • G_t 是从 t 步到结尾的折扣总回报，它当"评分"——拿高分的动作，其对数概率梯度被正向加权，以后更可能出现。
  • 无模型：只要能从环境中采样轨迹，就能用样本均值估计这个期望。

3. REINFORCE：最朴素的策略梯度

REINFORCE 就是上面公式的蒙特卡洛版：跑完一整条轨迹，用实际回报 G_t 当权重做梯度上升。

```

θ ← θ + α · Σ_t ∇_θ log π_θ(a_t|s_t) · G_t

```

  • 优点：思想干净，梯度无偏——必定往期望更好的方向走。
  • 致命伤：方差爆炸。一条轨迹里运气成分大，G_t 忽高忽低，梯度方向抖得像醉汉（闭环第 14 期随机游走）。需要下面两味药来压方差。

4. 两味降方差的药：基线与 Critic

(1) 基线 b(s)：把权重从 G_t 换成 G_t − b(s)。只要 b 只依赖状态、不依赖动作，期望梯度零变化（证明见题目 2），但方差大幅降低——相当于"和平时水平比，这局算好还是差"。最自然的基线就是状态价值 V(s)，于是权重变成优势函数 A(s,a) = G_t − V(s)：比平均好多少，就往哪推多少。

(2) Actor-Critic（演员-评论家）：干脆再训一个网络 V_w(s) 当 Critic，在线估计优势，不必等整条轨迹跑完。用 TD 误差 δ_t = r_t + γV_w(s_{t+1}) − V_w(s_t) 当优势的一个"有偏但低方差"近似：

  • Actor（演员 = 策略 π_θ）：θ ← θ + α · δ_t · ∇_θ log π_θ(a_t|s_t)
  • Critic（评论家 = 价值 V_w）：w ← w + β · δ_t · ∇_w V_w(s_t)

Critic 在"预测下一步价值"（闭环第 8 期卡尔曼滤波的"先猜后校"、第 12 期 DQN 的目标网络），Actor 在"按点评调整表演"。两个网络各司其职、互相成就。

5. 闭环地图

  • RL 主线：第 9 期 老虎机 → 第 10 期 MDP 价值 → 第 11 期 TD/Q 学习（价值法）→ 第 12 期 DQN（价值法 + 函数近似）→ 本期 策略梯度（直接优化策略）
  • 梯度上升本体 = 第 4 / 5 期 SGD：把"期望回报"取负当损失，SGD 往上爬即可
  • 探索靠策略本身的随机性 = 第 3 期退火噪声 / 第 14 期随机游走
  • 优势 ≈ TD 误差 = 第 11 期自举、第 8 期预测-校正

三、四道代表性题目（点开看思路与答案）

题目 1 · REINFORCE 梯度手算基本功
解题思路：最简单的单状态老虎机：只有 1 个状态，两个动作 A / B，策略用 sigmoid 参数化 π_θ(A) = σ(θ)、π_θ(B) = 1 − σ(θ)。跑一条轨迹：选中动作 A，拿到总回报 G = 3。问在 θ = 0 处，∇_θ J(θ) 是多少？
对 sigmoid 有一个标准结论：d/dθ log σ(θ) = 1 − σ(θ)（因为 σ' = σ(1−σ)，除以 σ 即得）。REINFORCE 单样本梯度为 g = ∇_θ log π_θ(A) · G。代入 θ=0 时 σ(0)=0.5：
g = (1 − σ(0)) · G = (1 − 0.5) · 3 = 0.5 · 3 = 1.5
正负号也对得上：正 θ 会提高 P(A)，而 A 拿到了正回报，所以梯度应为正——推高 A 的概率，符合直觉。
答案：∇_θ J(0) = 1.5。梯度为正，说明应增大 θ 以提高动作 A 的概率。
题目 2 · 基线为什么无偏且能降方差
解题思路：证明"只要基线只依赖状态 b(s)、不依赖动作，减基线不改变期望梯度"，并说明为什么基线不能是动作的函数。
对任意状态 s，固定它，对动作求期望：
E_{a∼π}[ ∇_θ log π_θ(a|s) · b(s) ]
= Σ_a π_θ(a|s) · ( ∇_θ π_θ(a|s) / π_θ(a|s) ) · b(s)
= b(s) · Σ_a ∇_θ π_θ(a|s)
= b(s) · ∇_θ ( Σ_a π_θ(a|s) )
= b(s) · ∇_θ 1 = 0
关键在于 Σ_a π_θ(a|s) = 1 是常数，其梯度为 0。所以 E[∇logπ · b(s)] = 0，减去 b(s) 后期望梯度不变——无偏。
为什么 b 不能是 a 的函数：若 b = b(a,s)，则 E[∇logπ · b(a,s)] = Σ_a ∇π(a)·b(a,s)，一般无法抵消成 0，会引入偏差，破坏"策略梯度定理"的保证。因此标准基线是状态价值 V(s)（只依赖 s）。
为什么能降方差：G_t 里包含"这个状态本来就高回报"的水平项，它对"哪个动作更好"毫无信息量，却让梯度忽大忽小。减去一个与状态强相关的 b(s)（如 V(s)）就把这层"背景噪音"剥离掉，只留下"相对平均水平，这步是好是差"的优势，方差自然缩小。
答案：证明如上，E[∇logπ·b(s)] = b(s)·∇1 = 0，故无偏；基线必须只依赖状态、不依赖动作，否则有偏。降方差源于剥离了与动作无关的状态背景奖励。
题目 3 · Actor-Critic 一步更新
解题思路：Critic 用线性价值 V_w(s) = w · s，当前 w = 0.5。观察到一步转移：s_t = 2，执行动作后得即时奖励 r_t = 1，下一状态 s_{t+1} = 3，折扣 γ = 0.9。给定该动作的对数概率梯度 ∇_θ log π_θ(a_t|s_t) = 0.5，学习率 α = 0.1，Critic 学习率 β = 0.1。求 TD 误差 δ、Actor 参数增量 Δθ、Critic 参数更新后的 w。
先算 TD 误差（当优势的近似）：
δ = r_t + γ·V_w(s_{t+1}) − V_w(s_t)
= 1 + 0.9 · (0.5 · 3) − (0.5 · 2)
= 1 + 0.9 · 1.5 − 1.0
= 1 + 1.35 − 1.0 = 1.35
Actor 更新：
Δθ = α · δ · ∇_θ log π = 0.1 · 1.35 · 0.5 = 0.0675
Critic 更新，∇_w V_w(s) = s = 2：
Δw = β · δ · ∇_w V_w(s_t) = 0.1 · 1.35 · 2 = 0.27
w_new = 0.5 + 0.27 = 0.77
答案：δ = 1.35，Δθ = 0.0675，w 由 0.5 更新为 0.77。
题目 4 · 连续动作为什么 DQN 做不到、策略梯度能
解题思路：这就是本期故事里阿明卡住的场景。设策略网络输出一个高斯分布：动作 a ∼ N( μ(s), σ² )，其中均值 μ(s) = θᵀs，标准差 σ 固定（与 θ 无关）。请写出 ∇_θ log π_θ(a|s) 的显式形式，并说明它如何化解 DQN 在连续动作上的困境。
高斯密度：
π_θ(a|s) = (1 / (σ√(2π))) · exp( −(a − μ)² / (2σ²) )
取对数：
log π_θ(a|s) = −(a − μ)² / (2σ²) − log( σ√(2π) )
对 θ 求梯度（σ 与 θ 无关，对数常数项消失，且 μ = θᵀs）：
∇_θ log π_θ(a|s) = ∇_θ[ −(a − μ)² / (2σ²) ]
= −(1/(2σ²)) · 2(a − μ) · (−∇_θ μ)
= (a − μ)/σ² · ∇_θ μ
= (a − μ)/σ² · s
即 ∇_θ log π = s · (a − μ) / σ²。
为什么化解困境：DQN 需要对每个动作算 Q 值再 argmax，连续动作空间不可枚举、离散化丢精度；而策略梯度直接对"采样出的那个连续动作"算对数概率梯度，用"实际动作偏离均值多少"来微调 θ——连续空间天然支持，无需枚举。这正是策略梯度相比价值法最硬核的优势。
答案：∇_θ log π_θ(a|s) = s · (a − μ) / σ²，其中 μ = θᵀs。它通过对连续动作的对数概率求导，让策略能直接在连续空间中学习，绕开了 DQN 必须离散化 / 枚举动作的死结。
