每日概率学 · 第 4 期

  • 日期：2026-09-18（周五）
  • 今日概念：全概率公式（Law of Total Probability）——"分而治之"，把一条总概率拆成几条"起因支路"再加起来
  • 一句话心智模型：当你想知道一件结果 B 发生的总概率，而 B 可能由好几种互斥且穷尽的前因 A₁, A₂, … 分别导致，那就先按"起因"把样本空间切块，再 P(B) = Σ P(Aᵢ)·P(B|Aᵢ) 汇总。

一、故事引入：阿明超市的"神秘次品灯泡"

阿明开了家小超市，灯泡统一从三家供应商进货，三家瓜分了全部货源，彼此不重叠：

| 供应商 | 占进货比例（先验份额） | 该家灯泡的次品率 |

| --- | --- | --- |

| 甲厂 | 50% | 2% |

| 乙厂 | 30% | 4% |

| 丙厂 | 20% | 5% |

一天，阿明闭眼从仓库随机抽了一只灯泡，一通电——不亮（次品）。

朋友大刘问："三家次品率最高才 5%，你这只次品的'总概率'到底多大？直接平均 (2%+4%+5%)/3 ≈ 3.67% 行不行？"

阿明摇头：

"不行。因为你抽到的灯泡，来自甲家的可能性（50%）远大于丙家（20%）。简单平均等于给三家'同等话语权'，但真实世界里甲家说话最大声。正确算法是按各自份额加权："

```

P(次品) = 50%×2% + 30%×4% + 20%×5%

= 0.01 + 0.012 + 0.01

= 0.032 = 3.2%

```

大刘恍然大悟："哦——所以'总次品率'不是各厂次品率的平均，而是各自份额当权重、乘上各自次品率、再加总？"

"对。"阿明在纸上画出三岔路口的图：

"每只灯泡必定来自甲、乙、丙三家之一（互斥且穷尽），它'次品'这件事，就是顺着这三条支路分别'走'到次品的总和。这就是全概率公式。"

二、概念讲解

1. 什么是"划分"（Partition）

设样本空间 Ω（所有可能结果）能被若干事件 A₁, A₂, …, Aₙ 完全切分：

  • 互斥：任意两个 Aᵢ 不能同时发生（Aᵢ∩Aⱼ = ∅）；
  • 穷尽：它们合起来覆盖全部，A₁∪A₂∪…∪Aₙ = Ω，且每个 P(Aᵢ) > 0。

故事里，甲/乙/丙三家就是这样一个划分——一只灯泡必属其一、且仅属其一。

2. 全概率公式

对任意事件 B（比如"次品"）：

```

P(B) = Σᵢ P(Aᵢ) · P(B | Aᵢ)

```

意思是：B 的总概率 = 每条"起因支路"的（先走到 Aᵢ 的概率）×（在 Aᵢ 已发生的条件下 B 发生的概率），再把各支路相加。

3. 它和贝叶斯定理的关系（承上启下）

回看第 2 期贝叶斯：

```

P(Aᵢ)·P(B|Aᵢ) 某支路"贡献"的次品量（分子）

P(Aᵢ|B)= ─────────────── = ──────────────────────────────

Σⱼ P(Aⱼ)·P(B|Aⱼ) 所有支路"贡献"的次品总量（分母）

```

全概率公式算的正是贝叶斯分母那个"归一化总证据"。上期我们直接给了"总概率"，本期你亲手学会怎么把它算出来——这就是贝叶斯的"前半段"。

💡 一句话心法：结果 B 的总概率，等于沿着每一条互斥且穷尽的"前因支路"走到的概率之和。先切块，再加权，最后汇总。

题目 1 · 两枚不同硬币

阿珍有两枚硬币：硬币 A 是公平的（正反各 1/2），硬币 B 是"双面正"（两面都是正面）。她随机选一枚（各 1/2 概率），抛一次，结果是正面。

现在问：这次抛出的"正面"，来自公平硬币 A 的概率是多少？（先用全概率确认"出现正面的总概率"，再结合上期贝叶斯给后验。）

题目 2 · 三个车间与总次品率（综合）

某厂三个车间生产同一种零件，产量占比与次品率如下：

  • 一车间：40%，次品率 3%
  • 二车间：35%，次品率 5%
  • 三车间：25%，次品率 2%
全厂随机抽一件零件，它是次品的总概率是多少？若抽到的恰是次品，它最有可能来自哪个车间？

题目 3 · 天气与迟到（生活化）

小柯上班有两种天气情况互斥且穷尽：晴天（概率 0.7）、雨天（概率 0.3）。

  • 晴天迟到概率 0.1；雨天迟到概率 0.4。
小柯某天迟到的总概率是多少？若他今天迟到了，更可能是因为雨天还是晴天？

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1：划分 = {选 A, 选 B}，各 1/2。P(正面|A)=1/2，P(正面|B)=1。

全概率：P(正面) = 1/2×1/2 + 1/2×1 = 1/4 + 1/2 = 3/4。

后验（贝叶斯）：P(选 A | 正面) = (1/2×1/2) ÷ (3/4) = 1/3。

  • 心法：虽然"正面"更可能来自 B，但 A 也被选中了，后验要按"贡献占比"算，不是看谁的 P(正面|Aᵢ) 大。
  • 题目 2：P(次品) = 0.40×0.03 + 0.35×0.05 + 0.25×0.02

= 0.012 + 0.0175 + 0.005 = 0.0345（3.45%）。

三支路"次品贡献"分别为 0.012 / 0.0175 / 0.005，总和 0.0345；

后验最大者是二车间 0.0175÷0.0345 ≈ 50.7%（二车间次品率虽高、产量居中，却贡献最多次品）。

  • 心法：总概率看加权；后验最大不一定是"次品率最高"的那家，而是"份额×次品率"乘积最大者。
  • 题目 3：P(迟到) = 0.7×0.1 + 0.3×0.4 = 0.07 + 0.12 = 0.19（19%）。

后验：P(雨天|迟到) = 0.12 ÷ 0.19 ≈ 63.2% —— 虽雨天只占 30%，却贡献了迟到的大头，所以"迟到更可能因雨天"。
