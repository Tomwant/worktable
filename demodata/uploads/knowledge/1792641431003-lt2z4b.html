每日概率学 · 第 7 期

  • 日期：2026-09-27（周日）
  • 今日概念：生日悖论（Birthday Paradox）——"一个房间只要 23 人，就有超过一半的概率，至少两人生日相同"
  • 一句话心智模型：不是'谁和我同一天'，而是'任意两个人之间有没有一对同天'。 人脑会本能地把问题想成"小概率撞我的生日"，但真正发生的是 n(n−1)/2 对组合在同时"抽签"，组合一多，巧合就不再是巧合。

一、故事引入：阿明的 50 元赌局

周末同学聚会，来了 30 位老同学。酒过三巡，阿明突然放下杯子：

"我赌 50 块——在座的 30 个人里，至少有两个人，生日是同一天。"

大刘嗤笑一声："一年 365 天，30 个人？撞上的概率顶多百分之几吧。我跟你赌！"

他心里盘算：30 个人，每个人"分到"一天，365 天里挑 30 天，那得多巧才能撞上？大概……二十几分之一？稳赢。

阿明笑着摇手指："你算错账了。等你掏钱的时候，别怪我没提醒。"

结果一查——真的有两位同学，都是 11 月 8 日生日。大刘乖乖付了 50 块，一脸不甘："这才 30 个人啊！凭什么？"

阿明在餐巾纸上写下一行：

30 个人，能两两配对多少对？—— C(30,2) = 30×29÷2 = 435 对。

"你看，"阿明说，"你脑子里想的是'有没有人撞我的生日'，那确实难。但问题是'这 435 对里，有没有任意一对撞上同一天'。每对撞上的概率虽然只有 1/365，可你有 435 个机会窗口在同时试。窗口多了，总撞上的概率自然就飞起来了。"

大刘愣住："所以不是'30 挑 365'，是'435 对每对都去撞 1/365'？"

"对。而且更吓人的是——只要 23 个人，这个概率就已经过半了。"阿明补了一句，"23 人，一半以上概率有人同生日；50 人，几乎肯定（97%）；到 70 人，概率超过 99.9%。"

💡 这就是生日悖论：结论反直觉，但数学上没有魔法，只是组合爆炸被人类的直觉严重低估了。

二、概念讲解

1. 朴素直觉为什么错

大多数人听到"生日相同"，脑子里自动翻译成："有没有人，和我同一天生日？"

这是一个指定匹配问题——难度确实高，需要约 253 人才能有一半概率撞上你的生日（见题目 2）。

但生日悖论问的是任意两人匹配：只要 30 人里存在某一对同天就算赢。问题从"n 个独立的小概率"变成了"n(n−1)/2 个机会窗口同时抽签"，难度天差地别。

2. 配对视角（最直观）

n 个人能组成 C(n,2) = n(n−1)/2 对。每一对"恰好同天"的概率约 1/365。

  • n = 23 → 253 对
  • n = 30 → 435 对
  • n = 50 → 1225 对

"机会窗口"数量随 n 平方级增长，而直觉只按 n 的线性在估算——这就是反直觉的根源。

3. 补集计算（最严谨）

直接算"至少一对相同"很麻烦（要枚举哪些对撞上），但算它的反面"全都不一样"很容易：

```

P(全不同) = 365/365 × 364/365 × 363/365 × … × (365−n+1)/365

P(至少一对相同) = 1 − P(全不同)

```

含义：第 1 个人随便哪天（365/365），第 2 个人避开他（364/365），第 3 个人避开前两人（363/365）……依次相乘。

4. 一个好用的近似

当 n 不太大时，有近似公式：

```

P(至少一对相同) ≈ 1 − e^( −n(n−1) / (2×365) )

```

代入 n = 23：指数 = −23×22/730 ≈ −0.693，e^(−0.693) ≈ 0.500，所以 P ≈ 50.7%——正好过半。

代入 n = 30：指数 ≈ −1.192，e^ ≈ 0.303，P ≈ 69.7%。

5. 几个关键数字（建立直觉）

| 人数 n | 至少一对同生日的概率 |

|---|---|

| 10 | ≈ 11.7% |

| 20 | ≈ 41.1% |

| 23 | ≈ 50.7% |

| 30 | ≈ 70.6% |

| 40 | ≈ 89.1% |

| 50 | ≈ 97.0% |

| 60 | ≈ 99.4% |

💡 一句话心法：反直觉的不是概率算错了，而是人脑不会自动把"n 个人"换算成"n²/2 对组合"。一旦你用配对视角看，23 人就过半一点也不奇怪。

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1：用近似 P ≈ 1 − e^(−n(n−1)/(2×365))。
  • n = 40：指数 = −40×39/730 ≈ −2.137，e^ ≈ 0.118，P ≈ 88.2%。
  • n = 50：指数 = −50×49/730 ≈ −3.356，e^ ≈ 0.0348，P ≈ 96.5%。
  • 直觉误区：人想的是"40 个人去碰 1/365（指定匹配）"，但其实是 C(40,2)=780 对同时抽签，窗口数量碾压单点概率。
  • 心法：从 40 到 50 只多了 10 人，概率却从 88% 跳到 96.5%——平方增长在 n 较大时提速极猛。
  • 题目 2：差别在"机会窗口"的数量级。
  • 指定匹配（找人和"我"同天）：相当于 n 个独立事件各自去碰 1/365 的小概率，期望碰撞数 ≈ n/365；要到 n≈253 才让"至少一次"接近 0.5（因为 253/365≈0.69，用 1−e^−0.69≈0.5）。这是线性增长。
  • 任意匹配（生日悖论）：机会窗口是 C(n,2)≈n²/2，增长是平方级。23 人时窗口已达 253，和"指定匹配需 253 人"恰好同数，但代价只是 23 个人——这就是不对称的根源。
  • 一句话：一个是 n 个窗口，一个是 n²/2 个窗口，差一个数量级很正常。
  • 题目 3：
  • ① 32 × 0.507 ≈ 16.2，即约 16 支球队会至少有一对同生日。真实世界杯（如 2002/2006/2010 等）统计下来，确实大约一半球队出现同生日，与理论高度吻合——这反而是验证生日悖论最漂亮的"自然实验"。
  • ② 哈希碰撞是同一个数学结构：哈希空间大小 H，要"任意两个文件哈希相同"，只需约 1.18×√H 个文件就有 50% 概率撞上（"生日界"），远低于穷举 H 个。所以 128 位哈希（H≈3.4×10³⁸）安全，而 32 位哈希（H≈4.3×10⁹）在几十万文件量级就危险——密码学里这叫 birthday attack（生日攻击）。本质和第 7 期完全一致：n² 级的机会窗口，让"任意碰撞"远比"指定碰撞"容易。
