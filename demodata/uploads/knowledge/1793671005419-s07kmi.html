第 9 期 · 强化学习中的探索与利用（ε-贪心 / 多臂老虎机）

今日概念：探索-利用困境（Exploration–Exploitation Dilemma） 与 ε-贪心（ε-greedy） 算法。
一句话：当你面对一堆"回报未知"的选项、且每个选择都消耗一次机会时，是该反复薅已知最好的那个（利用），还是匀出一部分机会去探明未知（探索）？这个权衡，是现代强化学习最底层的灵魂问题。

一、故事引入：阿明的"三杯试验奶茶"

阿明在店里新上了三款试验饮品，代号 A、B、C。每款的真实好评率是固定的（比如分别是 10%、50%、90%），但谁也不知道——只有卖出去、收回评价，才能一点点逼近真相。

规则很现实：

  • 每天阿明只能主推一款，卖出去的客人给好评（记 1）或差评（记 0）；
  • 推过的款会积累"经验均值"，但样本少时这个数字忽上忽下，不可全信；
  • 阿明总共只有有限的推广天数（比如 100 天），机会用尽就结束了。

于是阿明陷入两难：

  • 如果只推第一天碰巧不错的 A，可能错过真正最好的 C；
  • 如果每天轮换着试，流量又被浪费在差款上，错过赚好评的窗口。

这，就是强化学习的探索-利用困境。它最经典的玩具模型叫多臂老虎机（Multi-Armed Bandit，MAB）——想象赌场一排老虎机（"臂"），每台赢钱概率不同且未知，你手里只有有限枚硬币，该怎么拉，才能赚得最多？

二、概念讲解

1. 多臂老虎机模型

  • 有 K 个臂，臂 i 的回报是一个期望为 μᵢ 的随机变量（常用伯努利：好评=1、差评=0）。
  • 目标：在 T 步内最大化累积回报，等价于最小化累计遗憾（Regret）。

2. 遗憾（Regret）—— 衡量你"亏了多少"

最优臂是 μ* = maxᵢ μᵢ。累计遗憾定义为：

R_T = T · μ* − Σ（每一步实际回报的期望）

它回答一个问题：*"如果一开始就全押最优臂，能多赚多少？"* 强化学习算法好坏，往往就看 R_T 随 T 长得多快。

3. ε-贪心（ε-greedy）—— 最简也是最常用的策略

每次决策：

  • 以概率 1 − ε 选当前经验均值最高的臂 → 利用；
  • 以概率 ε 从所有臂里随机挑一个 → 探索。

直觉：ε 就是"好奇心预算"。ε 太大→一直在瞎试；ε 太小→早早锁死在可能错的臂上。

4. 固定 ε 的毛病 & 衰减 ε

  • 固定 ε：永远有 ε 概率在瞎探索，每步期望遗憾卡在一个正数上 → R_T 随 T 线性增长 O(T)，再久也回不了头。
  • 衰减 ε（如 ε_t = 1/t 或 c/log t）：探索次数总量只 ≈ ln T 次，R_T 降到 O(log T)，利用阶段估计已足够准，遗憾增长被刹住。

5. 上置信界 UCB —— 比 ε-贪心更聪明

每次选：

a_t = argmax （经验均值 μ̂_a + c · √(ln t / N_a)）

第二项叫乐观Bonus：N_a 越小（越没试过），Bonus 越大，把"不确定"当作"可能更好"来乐观对待。它自动在探索与利用间切换——不用手调 ε。

6. 汤姆森采样（Thompson Sampling）

对每臂维护一个后验分布，每步从后验里采样一个值，取采样值最大的臂。它是 ε-贪心/UCB 的贝叶斯升级版，实践中遗憾下限最优、且实现极简（闭环第 2、8 期贝叶斯更新）。

7. 它闭环了哪些旧概念

  • 大数定律（第 6 期）：经验均值 μ̂ 随样本增多收敛到真值 μᵢ，这才有"利用"的底气。
  • 伯努利与期望（第 9 期）：每臂回报就是伯努利试验，μᵢ 即期望。
  • 期望决策（第 5 期）：静态"选一个最好的"是 Bandit 的特例。
  • 马尔可夫链（第 12 期）：只有一个状态的 MDP，就是 Bandit；加上状态转移就升级成完整强化学习。

三、代表性题目（含完整解题思路与答案）

下面四题把"探索-利用"从直觉掰成可算的数。先自己推一遍，再看答案。

题目 1 · ε-贪心的基本功（选臂概率）

三臂 K=3，设 ε = 0.2。当前经验均值：Ā = 0.3，B̄ = 0.6，C̄ = 0.2。

问：第 t 步，每个臂被选中的概率各是多少？

解题思路：ε-贪心下，"利用"以概率 1−ε = 0.8 锁定当前均值最高的臂（这里是 B）；"探索"以概率 ε = 0.2 在三个臂里均匀随机，即每个臂额外分到 0.2/3。
答案：
- B 被选中概率 = 0.8（利用） + 0.2/3（探索）≈ 0.8667
- A 被选中概率 = 0 + 0.2/3 ≈ 0.0667
- C 被选中概率 = 0 + 0.2/3 ≈ 0.0667
关键提醒：探索是"全员均匀随机"，不是只探索没选过的臂——所以连当前最好的 B 也有 0.0667 概率在探索时被翻到。

题目 2 · 遗憾到底怎么算（Regret 手算）

两臂：μ_A = 0.4，μ_B = 0.9，最优臂 μ* = 0.9。某策略在前 4 步全选 A，后 6 步全选 B，总步数 T = 10。

问：累计遗憾 R_T 是多少？

解题思路：R_T = 最优臂的理论总期望 − 实际累积期望。最优臂全程拉 B 能拿 10 × 0.9 = 9。实际：前 4 步每步期望 0.4、后 6 步每步期望 0.9。
答案：
- 实际累积 = 4 × 0.4 + 6 × 0.9 = 1.6 + 5.4 = 7.0
- R_T = 9 − 7.0 = 2.0
换个算法（逐步遗憾求和）：前 4 步每步亏 0.9 − 0.4 = 0.5 → 共 2.0；后 6 步选的就是最优臂，每步亏 0。合计仍是 2.0。这 2.0 就是"前 4 步瞎选 A 交的学费"。

题目 3 · 固定 ε 为何会"线性翻车"（概念辨析）

问：为什么说固定 ε 的累计遗憾随 T 线性增长（O(T)），而衰减 ε（如 ε_t = 1/t）能把遗憾压到 O(log T)？给直观解释，不必推严格上下界。

解题思路：抓住"探索是永不停止的固定概率事件"这一根。
答案：
- 固定 ε：每一步都有恰好 ε 的概率去随机探索，而随机时大概率（尤其臂差明显时）选到非最优臂，单步期望遗憾被锁在一个正数 ≥ ε·Δ（Δ 是次优臂与最优臂的均值差）。于是 R_T ≥ ε·Δ·T，随 T 线性增长——探索永不收敛，学费越交越多。
- 衰减 ε_t = 1/t：总探索次数 ≈ Σ(1/t) ~ ln T，即只在前 ln T 量级步数里认真试，之后几乎全利用。当样本够了，μ̂ 已逼近真值，利用阶段几乎不亏。于是遗憾 ≈ O(log T)。
- 顺带辨析：ε_t = c/√t 衰减太慢，探索总量 ≈ √T 量级，遗憾量级介于两者之间、仍偏"亚线性但比 log 慢"；工程上 1/t 或 c/(log t) 更常用，保证收敛。

题目 4 · UCB 的"乐观面对不确定性"（手算选臂）

四臂，当前步 t = 100（即 ln t ≈ 4.605）。各臂被选次数 N = (20, 30, 40, 10)，经验均值 μ̂ = (0.5, 0.7, 0.6, 0.8)。取 UCB 常数 c = 1。

问：计算每臂 UCB 值，并选出这一步该拉的臂。

解题思路：UCB 值 = 经验均值 + 乐观 Bonus，Bonus = c·√(ln t / N_a)。N_a 越小，Bonus 越大——把"没试够"翻译成"可能更好"。逐臂代入公式。
答案（取 √4.605 ≈ 2.146）：
- A：0.5 + √(4.605/20) = 0.5 + √(0.2303) = 0.5 + 0.480 ≈ 0.980
- B：0.7 + √(4.605/30) = 0.7 + √(0.1535) = 0.7 + 0.392 ≈ 1.092
- C：0.6 + √(4.605/40) = 0.6 + √(0.1151) = 0.6 + 0.339 ≈ 0.939
- D：0.8 + √(4.605/10) = 0.8 + √(0.4605) = 0.8 + 0.679 ≈ 1.479
这一步选 D 臂（UCB ≈ 1.479 最大）。
点睛：D 既经验均值最高（0.8）、又被试得最少（N=10，Bonus 最大），UCB 同时奖励了"看起来好"和"不确定"，这就是它比死板 ε-贪心聪明的地方——探索是定向的，而非撒胡椒面。
