第 11 期 · 时序差分与 Q 学习（边走边学，自己悟出最优策略）

今日概念：时序差分（Temporal Difference, TD）学习与 Q 学习——一类"无模型、在线、边走边学"的强化学习方法。
承接：第 10 期讲了「已知地图和奖励」时怎么算出最优价值 V*（MDP + 贝尔曼方程）；本期讲「没有地图」时，智能体如何只靠走过的经验，自己摸索出最优策略。

一、故事引入：取餐机器人不靠"说明书"也能学会找路

还记得第 10 期那只取餐机器人吗？它当时卡在墙角，是因为大刘先给了它一张完整地图（状态转移概率 P、即时奖励 R），然后用贝尔曼方程算出了"每个格子值多少钱"的最优价值 V*。

但真实世界哪来的完整地图？阿明这次把机器人直接丢进一座陌生商场，只给它每走一步的"小提示"：撞墙 −1、顺利到取餐点 +10。没有路线图，没有概率表，连"终点在哪"都没告诉它。

怪物一样的变化发生了：机器人前几百趟东撞西撞、傻乎乎地乱走，但几百趟之后，它居然把每个格子"值多少钱"估得准准的，还自己摸清了最短路线——它从没看过任何说明书，却"悟"出了最优走法。

它是怎么做到的？—— 这就是时序差分（TD）学习和Q 学习。一句话概括：它每走一步，就用"这一步的奖励 + 对下一步的粗略估计"去修正对当前位置的估值，像滚雪球一样越估越准。

二、核心概念

1. 学价值的"三兄弟"：DP、MC、TD

强化学习要算的是"某个状态/动作值多少"（价值）。三种经典路子，差别只在靠什么信息来学：

  • 动态规划 DP（第 10 期）：知道环境模型 P、R，直接用贝尔曼期望方程算。要"上帝视角"，现实里往往没有。
  • 蒙特卡洛 MC：不用模型，但必须等一整趟跑完，拿真实总回报 G_t 去做平均。无偏但慢，长任务/连续任务直接崩。
  • 时序差分 TD：不用模型、也不用跑完。每走一步，拿"这一步奖励 + 下一步的估计价值"反推当前价值 → 在线、增量、边走边学。
一句话记忆：DP 靠"已知模型"，MC 靠"整趟真实回报"，TD 靠"一步样本 + 自举"。

2. TD(0) 更新公式（自举 bootstrap）

TD 的灵魂是用估计去更新估计（自举，bootstrap），不等待真实结局：

  • TD 误差：δ_t = R_{t+1} + γ · V(S_{t+1}) − V(S_t)
  • TD(0) 更新：V(S_t) ← V(S_t) + α · δ_t

其中 α 是学习率（接第 4 期 SGD 的学习率，控制"改多大步"），γ 是折扣因子（接第 10 期 MDP，控制"多远未来的奖励还值钱"）。

3. 为什么 TD 又快又稳

  • 在线：每步即可更新。一条 1 万步的长轨迹，MC 要憋到跑完才知道起点价值，TD 走一步就能改一次——长任务里 TD 远胜 MC。
  • 低方差但有偏：只采样一步，方差小；用估计值带来偏差（MC 无偏但高方差，接第 19 期重尾分布里"方差爆炸"的讨论）。合理 α 下 TD 通常更快收敛。
  • 闭环：它的"老师"正是第 10 期的贝尔曼期望方程 V = R + γV'；第 6 期大数定律保证多次平均后收敛；第 9 期 ε-贪心保证把每个格子都踩遍；第 12 期马尔可夫链保证收敛到不动点。

4. Q 学习：直接学"在哪个格子该往哪走"

TD 学的是状态价值 V(s)（"这个格子值多少"），还得另配策略才知道怎么走。Q 学习学的是动作价值 Q(s,a)（"在这个格子选这个动作值多少"），一步到位：

  • Q 学习更新（离线策略 off-policy）：

Q(s,a) ← Q(s,a) + α · [ R + γ · max_{a'} Q(s',a') − Q(s,a) ]

  • 关键魅力：用 max 逼近最优，不依赖你实际怎么走，最终收敛到最优动作价值 Q*（正是第 10 期贝尔曼最优方程 Q* = max_a (R + γ·Q*) 的采样版）。也就是说，哪怕你瞎探索，Q 表最终也能告诉你"理论最优该怎么走"。

5. SARSA：低调务实的兄弟（在线策略 on-policy）

SARSA 把 max 换成"实际下一步动作 a' "的 Q 值：

  • Q(s,a) ← Q(s,a) + α · [ R + γ · Q(s',a') − Q(s,a) ]
  • 区别：Q 学习学"理论最优可能"（更激进），SARSA 学"在当下探索策略下实际能拿到的价值"（更保守，撞墙更少）。同一环境，Q 学习可能为了赌最优而多撞几次墙，SARSA 则稳扎稳打。

6. 收敛与"死亡三角"

  • 表格 Q 学习：只要每个 (s,a) 被无限次访问，且 α 满足 Robbins-Monro 条件（Σα = ∞ 且 Σα² < ∞，接第 4 期 SGD 学习率衰减），就必收敛到 Q*。
  • 换成神经网络近似 Q（DQN 之前）：会发散！祸根是被称作死亡三角的三件套——离轨（off-policy 的 max）+ 自举（用估计更新估计）+ 函数逼近（神经网络）叠在一起，使"更新目标"自己和自己纠缠、越学越飘。
  • 救法（DQN 双支柱）：① 经验回放（把历史转移存进池子随机采样，打散相关性，接第 15 期蒙特卡洛/第 5 期 SGLD 的噪声思想）；② 目标网络（用一份缓慢同步的副本当固定的"老师"目标，抑制自举抖动，接第 8 期粒子滤波的目标分布）。

7. 应用版图

游戏 AI（AlphaGo、Atari 打砖块）、机器人控制、推荐系统、自动驾驶决策、电网/物流调度优化。

三、代表性题目（含完整解题思路与答案）

下面四题覆盖"手算基本功 → Q 学习 vs SARSA → ε-贪心衔接 → 概念辨析与发散"，建议先自己推一遍，再看答案。

题目 1 · TD(0) 手算基本功

题目：机器人走迷宫，轨迹为 路口A → 走廊B → 终点（吸收态）。单步奖励：A→B 得 0，B→终点 得 +10；终点之后的价值 V(终点)=0。初始所有 V=0，学习率 α=0.5，折扣 γ=0.9。按经过顺序先更新 B、再更新 A，求最终 V(走廊B) 与 V(路口A)。
解题思路：TD(0) 是"从后往前"逐步反推。先算离终点近的 B：B 这一步拿到奖励 10，且到终点后价值 0，所以 δ_B = 10 + 0.9·0 − 0 = 10，V(B) = 0 + 0.5·10 = 5。再用 B 的新价值反推 A：A→B 拿 0 奖励，但 B 现在值 5，所以 δ_A = 0 + 0.9·5 − 0 = 4.5，V(A) = 0 + 0.5·4.5 = 2.25。注意 A 用的是更新后的 V(B)（在线学习），这正是"一边走一边改地图"的精髓。
答案：V(走廊B) = 5，V(路口A) = 2.25。

题目 2 · Q 学习 vs SARSA，同轨迹差在哪

题目：状态 s="路口"，执行动作 a="直行" 得奖励 r=1，落到 s'="路口B"；s' 处各动作价值 Q(s',左转)=2、Q(s',直行)=0.5、Q(s',右转)=1（即 max_{a'}Q(s',a') = 2）。初始 Q(s,直行)=0，α=0.5，γ=0.9。
（1）若用 Q 学习 更新，新 Q(s,直行) = ?
（2）若实际下一步执行的动作是 a'="直行"（其 Q=0.5），用 SARSA 更新，新 Q(s,直行) = ?
（3）两者之差说明什么？
解题思路：Q 学习用 s' 处的最大 Q 值（理论最优可能），SARSA 用实际走的那一步 a' 的 Q 值（真实发生）。
- Q 学习：目标 = 1 + 0.9·2 = 2.8，更新 = 0 + 0.5·(2.8 − 0) = 1.4。
- SARSA：目标 = 1 + 0.9·0.5 = 1.45，更新 = 0 + 0.5·(1.45 − 0) = 0.725。
差 = 0.675。
答案：（1）Q 学习得 1.4；（2）SARSA 得 0.725；（3）Q 学习更"乐观/激进"——它学的是"如果接下来走最优能拿多少"，所以敢把当前动作估高、愿意冒险；SARSA 学的是"在当下探索策略下实际能拿多少"，更保守、撞墙更少。同一环境两者最终策略可能不同。

题目 3 · ε-贪心 + Q 学习（接第 9 期）

题目：某状态三动作当前 Q 值：Q(A)=2，Q(B)=3，Q(C)=1。采用 ε-贪心（ε=0.1）选动作。
（1）选中各动作的概率分别是多少？
（2）若实际选了 B，得即时奖励 r=0.5，落到新状态后该状态最优动作价值 max Q* = 4，α=0.5，γ=0.9，问更新后的 Q(B) = ?
解题思路：（1）ε-贪心：以 1−ε = 0.9 的概率选当前最大 B，以 ε = 0.1 均匀分给三个动作。故 P(B) = 0.9 + 0.1/3 ≈ 0.9333，P(A) = P(C) = 0.1/3 ≈ 0.0333。
（2）Q 学习更新：目标 = 0.5 + 0.9·4 = 4.1，更新 = 3 + 0.5·(4.1 − 3) = 3 + 0.5·1.1 = 3.55。
答案：（1）P(B) ≈ 0.933，P(A) = P(C) ≈ 0.033；（2）Q(B) 更新后 = 3.55。

题目 4 · 概念辨析 + 神经网络为什么会翻车

题目：（1）一句话区分 TD、MC、DP 各自"靠什么学价值"？
（2）一条 1 万步的超长轨迹，用 MC 和用 TD(0) 估计起点价值，体验上差在哪？
（3）朴素表格 Q 学习能收敛，但把 Q 换成神经网络后就发散，为什么？怎么救？
解题思路：
（1）DP 靠"已知环境模型 + 贝尔曼方程"（上帝视角）；MC 靠"跑完整趟的真实回报平均"（无模型但要等结局）；TD 靠"一步样本 + 下一步的估计价值自举"（无模型、在线、不等结局）。
（2）MC 必须憋到 1 万步跑完才知道起点值，长任务极慢且中途无法利用；TD 每走一步就能更新一次起点估计，几百步就开始收敛，在线优势巨大。
（3）发散源于死亡三角：离轨（off-policy 的 max）+ 自举（用估计更新估计）+ 函数逼近（神经网络）三者叠加，使更新目标自己和自己纠缠、不收敛。救法：① 经验回放（把历史转移存池子随机采样，打散相关性，接第 15 期蒙特卡洛/第 5 期 SGLD 的噪声思想）；② 目标网络（用一份缓慢同步的副本当固定"老师"目标，抑制自举抖动，接第 8 期粒子滤波的目标分布）。这两招正是 DQN 的核心。
答案：（1）DP 靠模型、MC 靠整趟真实回报、TD 靠一步采样+自举；（2）MC 要等跑完、TD 每步可更新，长任务 TD 远快；（3）死亡三角导致发散，靠经验回放 + 目标网络化解（DQN）。

四、今日小结

  • TD 用"下一步的估计"反推当前价值（自举），在线、增量、不依赖模型，是连接 DP（有模型）与 MC（等结局）的桥梁。
  • Q 学习用 max 逼近最优动作价值，离线策略、直接学"怎么走最值"；SARSA 用实际动作，更保守务实——两者是强化学习"价值派"的两张脸。
  • 表格法收敛靠"访遍每个 (s,a) + 合适 α"；一旦上神经网络，必须防死亡三角（经验回放 + 目标网络）。

五、明日预告（第 12 期）

深度 Q 网络 DQN 与经验回放——把 Q 学习搬进神经网络，用"经验回放池 + 目标网络"稳稳驯服死亡三角，让 AI 从游戏像素直接学会打游戏。我们会亲手算一遍：回放怎么打乱相关性、目标网络怎么当"慢半拍的老师"。
