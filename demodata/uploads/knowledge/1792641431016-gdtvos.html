每日概率学 · 第 11 期

  • 日期：2026-10-07（周三）
  • 今日概念：协方差与相关性（Covariance & Correlation）——前几期我们都在研究"一个随机量长什么样"（分布、期望、方差）。但从今天起，概率学要开始关心两个量之间"是不是一起动"。身高和体重是不是手拉手涨？冰淇淋卖得多、溺水是不是也多？这俩问题靠"方差"答不了，得用协方差 Cov(X,Y) 看"方向"（同涨同跌还是反着来），再用相关系数 r = Corr(X,Y) 把它标准化成 −1 到 1 之间的"亲密程度"。但请务必记住两个最坑人的真相：① 相关 ≠ 因果；② r = 0（不相关）≠ 两个量没关系（独立）。
  • 一句话心智模型：协方差告诉你"两个量往不往一块儿走"（带单位、看方向）；相关系数 r 把这种"一起走"的程度压进 [−1, 1]，r=1 完全同步、r=−1 完全反向、r=0 没有线性关系。但 r 只量"线性"关系，且"一起动"不代表"一个导致另一个"——r 高可以是第三个变量在背后同时抬高两条线。

一、故事引入：阿明的"冰淇淋杀人论"

阿明刷手机刷到一条新闻，拍案而起："大刘！我找到因果关系了——某海滨城市，冰淇淋卖得越多，溺水的人也越多！所以吃冰淇淋会导致溺水！我以后再也不吃了！"

大刘头都没抬："你这因果是拿脚后跟想出来的。"

"数据明摆着啊，两条线一起往上涨！"

"对，两条线确实一起涨——这叫'相关'。但你搞错的是中间那根因果箭头。"大刘在纸上画了三个圈，"真正的原因是天热：天一热，大家既爱买冰淇淋，又爱下海游泳；下海的人多了，溺水自然也多。气温是那个把两条线同时抬高的'幕后黑手'。等我把'气温'控制住——比方说只看同样热的那些天——冰淇淋销量和溺水人数之间的那点关系，基本就散了。"

阿明愣住："所以……'一起动'不等于'谁导致谁'？"

"正是。"大刘点头，"而且更反直觉的还在后头：有时候两个量'完全不一起动'（r = 0），它们却明明死死绑在一起。"

"不可能吧？"

"比如 X 在区间 [−1, 1] 上均匀乱取，令 Y = X²。你告诉我，X 和 Y 有没有关系？"

阿明想了想："Y 完全由 X 决定，当然有关系！"

"但算协方差，Cov(X, X²) = 0，r 也等于 0——你用'相关'这把尺子去量，它俩'毫无关系'。"大刘笑，"所以'相关'这把尺子，只能量'直来直去'的那种关系，量不了抛物线这种弯的。今天，我们就把'两个量一起动'这件事，量明白。"

💡 一句话先记住：协方差/相关系数量的是"线性关系"；相关高可能是因果、可能是反向因果、可能是第三个变量搅局；而且 r = 0 只代表"没有直线关系"，绝非"没关系"。

二、概念讲解

1. 协方差：两个量"往不往一块儿走"

对两个随机变量 X、Y，先各自减去自己的均值（中心化），再看"偏离方向是否一致"：

$$Cov(X,Y) = E\big[(X - \mu_X)(Y - \mu_Y)\big] = E[XY] - E[X]E[Y]$$

直觉解读：

  • Cov > 0：X 偏大时 Y 也往往偏大（同涨同跌里的"同涨"）——正相关。
  • Cov < 0：X 偏大时 Y 往往偏小——负相关。
  • Cov = 0：没有线性协同——不相关（线性意义上）。

⚠️ 协方差的毛病：它带单位。X 是"身高(cm)"、Y 是"体重(kg)"，Cov 的单位就是 cm·kg，数值大小随量纲乱变，没法直接说"亲密程度有多高"。

2. 相关系数 r：把"一起走"压进 [−1, 1]

把协方差除以两边各自的标准差，抹掉单位，得到皮尔逊相关系数：

$$r = Corr(X,Y) = \frac{Cov(X,Y)}{\sigma_X \, \sigma_Y}$$

它的性质极为干净：

  • 无单位，纯粹衡量"线性关系的强弱和方向"。
  • r ∈ [−1, 1] 恒成立（来自柯西–施瓦茨不等式）。
  • r = 1：Y 与 X 完全正线性相关（Y = aX + b，a > 0），所有点落在一条上升直线上。
  • r = −1：完全负线性相关（a < 0）。
  • r = 0：没有线性关系（点云既不上升也不下降地散布，或呈弯曲线）。
  • |r| 越接近 1，线性捆绑越紧；越接近 0，线性越松。
为什么 r 永远出不了 [−1, 1]？直觉版：把 X、Y 各自"标准化"成 (X−μ_X)/σ_X、(Y−μ_Y)/σ_Y，它们各自的方差都变成 1。此时 Cov = r。而对任意两个"方差为 1"的变量，柯西–施瓦茨告诉我们它们乘积的期望（也就是协方差）绝对值不可能超过 1——这就是 r 被锁在 [−1,1] 的来路。

3. 两个最坑人的真相

① 相关 ≠ 因果（最经典的坑）

"冰淇淋销量 ↔ 溺水人数"高度相关，但吃冰淇淋不导致溺水。常见三种伪装：

  • 混杂变量（confounder）：第三个变量 Z 同时影响 X 和 Y（如气温同时抬高冰淇淋与溺水）。
  • 反向因果：以为是 X 导致 Y，其实是 Y 导致 X（如"医院里的人更易生病"——是生病才去医院）。
  • 纯粹巧合 / 样本噪声：小样本里随便俩序列都能撞出高相关（网上那些"某国人均巧克力消费 vs 诺贝尔奖数"的搞笑图）。

② r = 0（不相关）≠ 独立（没关系）

这是第二个大坑。独立一定推出不相关（Cov = 0），但反过来不成立。

经典反例：X 在 [−1, 1] 上均匀分布，令 Y = X²。

  • Y 完全由 X 决定 ⇒ X、Y 显然不独立（知道 X 就知道 Y）。
  • 但 E[X] = 0，E[X³] = 0（奇函数在对称区间积分为 0），故

$$Cov(X,Y) = E[X\cdot X^2] - E[X]E[X^2] = E[X^3] - 0 = 0$$

于是 r = 0。

也就是说：用"线性相关"这把直尺去量一条抛物线，量出来是 0——但 X 和 Y 明明死死绑在一起。r 只捕捉"直线关系"，捕捉不了弯的、非线性的依赖。 所以"不相关"只能读成"没有线性关系"，绝不能读成"两个量互不影响"。

💡 心法：协方差看"方向"，相关系数 r 看"线性亲密程度（且被锁在 −1~1）"。两个雷区永记：相关不等于因果；r = 0 不等于独立。

题目 1 · 冰淇淋与溺水：一条被伪造的因果链

某海滨城市 6–8 月每日数据：冰淇淋销量 X 与溺水人数 Y 的样本相关系数高达 r ≈ 0.9。阿明据此宣称"吃冰淇淋导致溺水"。

① 这个 r ≈ 0.9 说明了什么（从"方向"和"强弱"两个角度说）？它能不能证明"冰淇淋导致溺水"？
② 大刘说"真正的原因是气温"。请用"混杂变量"的语言，讲清楚气温 Z 是如何同时抬高 X 和 Y 的。
③ 如果只挑"气温相同的那些天"再来算 X 与 Y 的相关，你预期这个偏相关会变大还是变小、趋近于多少？为什么？

题目 2 · 身高与体重：正相关，但胖子一定高吗？

成年男性群体中，身高 X 与体重 Y 呈现正相关，样本 r ≈ 0.6。

① r ≈ 0.6 说明什么？为什么 r 不是 1（即"身高定了，体重就完全确定"）？列出至少两个让 r 达不到 1 的原因。
② 既然身高体重正相关，为什么"胖子（体重高）不一定高（身高也高）"？用"相关 ≠ 确定性"解释这个直觉矛盾。
③ 如果画散点图，你预期点云大致是什么形状（一条紧绷的直线 / 一条松散上升的带 / 一个圆）？为什么？

题目 3 · 动手算：给 5 对数据，算出 r

下面是 5 个观测 (x, y)：(1, 2)、(2, 3)、(3, 5)、(4, 4)、(5, 6)。（本小题用"总体"公式，除以 n = 5）

① 先算均值：x̄ = ?，ȳ = ?
② 算出协方差 Cov = (1/5)·Σ(xᵢ − x̄)(yᵢ − ȳ) = ?
③ 算出各自标准差 σ_X、σ_Y，再求 r = Cov / (σ_X σ_Y) = ?（提示：两个标准差恰好相等，算起来很省事）
④ 这个 r 的大小说明 X、Y 之间线性关系"紧"还是"松"？

题目 4 · 不相关却绑死：Y = X² 的反例

设 X 在区间 [−1, 1] 上均匀取值（对称分布），令 Y = X²。

① 直观上，X 和 Y 有没有关系？知道 X 能不能推出 Y？
② 证明 Cov(X, Y) = 0：利用 E[X] = 0 与 E[X³] = 0（奇函数在对称区间积分为 0），套 Cov = E[XY] − E[X]E[Y]。
③ 既然 Cov = 0、r = 0，为什么我们不能说"X 和 Y 独立 / 没关系"？用一句话点破"r = 0 只意味着没有线性关系"。

四、提示（如需逐题完整推导，回复"揭晓答案"）

  • 题目 1（冰淇淋 ↔ 溺水）：
  • ① r ≈ 0.9：方向为正（两者同涨同跌），强度很强（接近 1）。但它不能证明因果——相关只描述"一起动"，不指明"谁导致谁"。
  • ② 气温 Z 是混杂变量：天热（Z 高）→ 人们买冰淇淋多（X 高）且下海游泳多（溺水 Y 高）；Z 同时抬高 X、Y 两条线，制造出虚假的 X↔Y 相关。
  • ③ 控制气温后，X 与 Y 的偏相关应大幅变小、趋近于 0——因为一旦"热不热"这个共同原因被固定，冰淇淋和溺水之间本就没有直接联系。
  • 题目 2（身高 ↔ 体重）：
  • ① r ≈ 0.6 表示中等偏强的正线性关系，但非完美。r ≠ 1 是因为体重还受基因、饮食、运动、肌肉量等众多与身高不完全同步的因素影响；且关系是"趋势"而非"定律"。
  • ② 相关是概率性/统计性的，不是确定性的函数关系：高个子平均更重，但个体上"矮而壮""高而瘦"都完全可能，所以"胖子不一定高"。
  • ③ 散点图应是一条松散上升的带状云（左下到右上，但点明显散布、不落在一条直线上），因为相关强但不完美。
  • 题目 3（动手算 r）：
  • ① x̄ = (1+2+3+4+5)/5 = 3；ȳ = (2+3+5+4+6)/5 = 4。
  • ② 偏差乘积：(−2)(−2)=4、(−1)(−1)=1、(0)(1)=0、(1)(0)=0、(2)(2)=4，合计 9；Cov = 9/5 = 1.8。
  • ③ σ_X² = (4+1+0+1+4)/5 = 2 ⇒ σ_X = √2 ≈ 1.414；同理 σ_Y² = (4+1+1+0+4)/5 = 2 ⇒ σ_Y = √2 ≈ 1.414；r = 1.8 / (√2·√2) = 1.8/2 = 0.9。
  • ④ r = 0.9 很接近 1，说明 X、Y 之间线性关系很紧（点云几乎贴着一条上升直线）。
  • 题目 4（Y = X²）：
  • ① 有关系：Y 完全由 X 决定（Y = X²），知道 X 立刻知道 Y——绝不独立。
  • ② Cov(X,Y) = E[X·X²] − E[X]·E[X²] = E[X³] − 0·E[X²] = 0（X 对称分布 ⇒ E[X]=0、E[X³]=0）。
  • ③ 因为 r = 0 只意味着"没有线性关系"，而 Y = X² 是完美的抛物线（非线性）依赖——直尺量不出弯的。所以"不相关（r=0）"绝不等于"独立 / 没关系"，这正是本期第二大雷区。
